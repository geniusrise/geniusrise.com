# Model name

WizardMath-7B-V1.0-GPTQ

## Links

- [Hugging Face Model Page](https://huggingface.co/TheBloke/WizardMath-7B-V1.0-GPTQ)

## Description

The WizardMath-7B-V1.0-GPTQ model is a language model capable of generating text. It is based on the WizardLM/WizardMath-7b-V1.0 base model and belongs to the llama model type. The model is quantized by TheBloke. It has a total of 1,131,335,680 parameters. The model can be used for tasks such as text generation. It supports the transformers library in Python. The model's prompt template provides an instruction for the task, and the response template suggests starting with step-by-step thinking.

## Usage example

Here is an example of how to use the model with the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model_name = "TheBloke/WizardMath-7B-V1.0-GPTQ"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# Encode the prompt
prompt = "Below is an instruction that describes a task. Write a response that appropriately completes the request.\n\n\n### Instruction:\n{prompt}\n\n\n### Response: Let's think step by step."
inputs = tokenizer.encode(prompt, return_tensors="pt")

# Generate a response
outputs = model.generate(inputs, max_length=100)

# Decode the response
response = tokenizer.decode(outputs[0])
print(response)
```
