# Model name

cross-encoder/nli-deberta-v3-small

## Links

- [Hugging Face Model Page](https://huggingface.co/cross-encoder/nli-deberta-v3-small)

## Description

The cross-encoder/nli-deberta-v3-small model is a transformer-based model trained for zero-shot classification tasks, specifically natural language inference (NLI) tasks. It is based on the deberta-v3-small architecture and is fine-tuned on the multi_nli and snli datasets. The model has been evaluated using the accuracy metric and is licensed under Apache-2.0. It is compatible with the transformers library and can be used for text classification tasks with the Python programming language.

## Usage example

```python
from transformers import pipeline

classifier = pipeline("zero-shot-classification", model="cross-encoder/nli-deberta-v3-small")
sequence = "I have a problem with my iPhone that needs to be resolved asap!!"
candidate_labels = ["urgent", "not urgent", "phone", "tablet", "computer"]

result = classifier(sequence, candidate_labels)
print(result["labels"])
```

This example demonstrates how to use the model for zero-shot classification. The given sequence is classified into one of the candidate labels provided.
