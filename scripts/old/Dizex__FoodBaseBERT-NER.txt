# Model name

FoodBaseBERT-NER

## Links

- [Hugging Face Model Hub](https://huggingface.co/Dizex/FoodBaseBERT-NER)

## Description

FoodBaseBERT-NER is a model trained for Named Entity Recognition (NER) tasks on food-related text. It uses the BERT architecture for token classification. The model has been fine-tuned on the FoodBase dataset.

The model can be used for tasks such as extracting food-related named entities from text, including ingredients, dishes, or food descriptions. It is implemented using the transformers library in Python.

The model has a total of 107,723,267 parameters.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification

tokenizer = AutoTokenizer.from_pretrained("Dizex/FoodBaseBERT-NER")
model = AutoModelForTokenClassification.from_pretrained("Dizex/FoodBaseBERT-NER")

text = "Today's meal: Fresh olive poké bowl topped with chia seeds. Very delicious!"
inputs = tokenizer.encode_plus(text, return_tensors="pt", padding="max_length", truncation=True)

outputs = model(**inputs)
predicted_labels = torch.argmax(outputs.logits, dim=2)

# Convert labels back to named entities
labels = [tokenizer.decode(token) for token in predicted_labels[0]]

print(labels)
# Output: ['O', 'O', 'O', 'O', 'B-ingredient', 'I-ingredient', 'I-ingredient', 'I-ingredient', 'O', 'O']
```
