## Description

google/umt5-base is a multilingual T5 (Text-to-Text Transfer Transformer) model developed by Google. It is built on the Transformers library in Python. This model is capable of performing text-to-text generation in multiple languages. It has been trained on a large dataset called mc4 and is licensed under Apache-2.0.

The model's architecture is UMT5ForConditionalGeneration, which is compatible with autotraining and endpoint deployment. The model's last modification date is July 3, 2023. It has been downloaded 1014 times and has received 10 likes.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("google/umt5-base")
model = AutoModelForSeq2SeqLM.from_pretrained("google/umt5-base")

input_text = "Translate this text into French: 'Hello, how are you?'"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output_ids = model.generate(input_ids)

output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)
print(output_text)
```

This example demonstrates how to use the google/umt5-base model for text translation. The input text is encoded using the model's tokenizer, and the generated output is then decoded back into readable text.
