## Description

The google/bigbird-pegasus-large-bigpatent model is a pre-trained language model trained by Google. It is based on the BigBird Pegasus architecture and is fine-tuned for text summarization tasks. The model is capable of generating high-quality summaries of text inputs.

This model is trained using the Transformers library with Python and is available for use in various NLP tasks, including text summarization.

The model has been trained on the big_patent dataset, and it has approximately 1.6 billion parameters.

For more details about the model configuration and usage instructions, refer to the [Hugging Face Model Page](https://huggingface.co/google/bigbird-pegasus-large-bigpatent).

## Usage example

Here is an example of how to use the google/bigbird-pegasus-large-bigpatent model with the Transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("google/bigbird-pegasus-large-bigpatent")
model = AutoModelForSeq2SeqLM.from_pretrained("google/bigbird-pegasus-large-bigpatent")

input_text = "This is a sample input text that needs to be summarized."
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output_ids = model.generate(input_ids)
output_text = tokenizer.decode(output_ids[0])

print("Input Text:")
print(input_text)
print("Summarized Output:")
print(output_text)
```
