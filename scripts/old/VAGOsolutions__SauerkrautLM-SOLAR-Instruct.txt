## Links

Original Hugging Face page: [VAGOsolutions/SauerkrautLM-SOLAR-Instruct](https://huggingface.co/VAGOsolutions/SauerkrautLM-SOLAR-Instruct)

## Description

SauerkrautLM-SOLAR-Instruct is a text generation model that can be fine-tuned using the Transformers library. It belongs to the LlamaForCausalLM architecture and the Transformers library. The model is primarily used for text generation tasks and supports languages such as English and German. It has been trained using the argilla/distilabel-math-preference-dpo dataset. The model has a total of 10,731,524,096 parameters.

## Usage example

To use the model with the Transformers library in Python, you can follow these steps:

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "VAGOsolutions/SauerkrautLM-SOLAR-Instruct"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)

input_text = "Generate text here"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

Please note that you need to have the Transformers library installed to run the code.
