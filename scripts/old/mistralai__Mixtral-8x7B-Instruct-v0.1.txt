## Description

The Mixtral-8x7B Large Language Model (LLM) is a pretrained generative Sparse Mixture of Experts (MoE). It has shown superior performance compared to the Llama 2 70B on multiple benchmarks. The model is compatible with the vLLM serving model as well as the Hugging Face transformers library.

### Instruction Format

The correct prompt format for instructions must be strictly followed, which is:

```
<s> [INST] Instruction [/INST] Model answer</s> [INST] Follow-up instruction [/INST]
```
Special tokens `<s>` and `</s>` represent the beginning and end of a string. `[INST]` and `[/INST]` are regular strings encapsulating the instruction provided by the user.

## Usage example

Using the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "mistralai/Mixtral-8x7B-Instruct-v0.1"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id)

text = "Hello my name is"
inputs = tokenizer(text, return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=20)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

Note that the model is in full precision by default, but adjustments can be made for half-precision or lower precision using `bitsandbytes`.

## Limitations

The Mixtral-8x7B Instruct does not have moderation mechanisms. The Mistral AI team is open to working with the community to develop moderated outputs for environments requiring them.
