# Model name
google/bigbird-pegasus-large-arxiv

## Links
- [Hugging Face Model Page](https://huggingface.co/google/bigbird-pegasus-large-arxiv)

## Description
The `google/bigbird-pegasus-large-arxiv` model is a large-scale transformer model trained for the task of summarization. It is based on the BigBird Pegasus architecture and uses the Pegasus framework for text-to-text generation. The model is trained on various datasets, including scientific papers, CNN/DailyMail articles, and XSum dataset. It has achieved competitive performance on multiple evaluation metrics such as ROUGE and meteor.

Key features of the model:
- Architecture: BigBirdPegasusForConditionalGeneration
- Model type: bigbird_pegasus
- Datasets: scientific_papers, CNN/DailyMail, XSum
- License: Apache 2.0

The model is implemented using the Transformers library in Python.

## Usage example
```python
from transformers import BigBirdPegasusForConditionalGeneration, BigBirdPegasusTokenizer

# Load the tokenizer and model
tokenizer = BigBirdPegasusTokenizer.from_pretrained("google/bigbird-pegasus-large-arxiv")
model = BigBirdPegasusForConditionalGeneration.from_pretrained("google/bigbird-pegasus-large-arxiv")

# Example input text
input_text = "The quick brown fox jumps over the lazy dog."

# Tokenize the input text
inputs = tokenizer.encode(input_text, return_tensors="pt")

# Generate a summary
summary_ids = model.generate(inputs["input_ids"])
summary = tokenizer.decode(summary_ids[0])

print("Input text:", input_text)
print("Summary:", summary)
```
