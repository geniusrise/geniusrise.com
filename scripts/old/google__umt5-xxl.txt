# Model name

Google/umt5-xxl

## Links

Hugging Face page: [https://huggingface.co/google/umt5-xxl](https://huggingface.co/google/umt5-xxl)

## Description

Google/umt5-xxl is a multilingual text-to-text generative model based on the UMT5 architecture. It has been trained on the `mc4` dataset and is compatible with the transformers library in Python. The model supports multiple languages and has a total of 900 million parameters. It is licensed under Apache 2.0.

## Usage example

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/umt5-xxl")
model = T5ForConditionalGeneration.from_pretrained("google/umt5-xxl")

input_text = "Translate this text into French: 'Hello, how are you?'"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output_ids = model.generate(input_ids)
output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)

print(output_text)
```

For more details and examples, refer to the [Hugging Face page](https://huggingface.co/google/umt5-xxl).
