## Description

politicalBiasBERT is a model developed by Bucket Research. It is a BERT-based model for text classification tasks, specifically designed for detecting political bias in text. The model is trained to classify text into different political bias categories. It is built using the transformers library in Python and is compatible with the AutoModelForSequenceClassification and AutoTokenizer classes.

The model has been trained on datasets specific to political bias detection and has a total of 108,313,091 parameters. It is a BERT model and utilizes the transformers library for training and inference. The model's architecture is based on BertForSequenceClassification.

## Usage example

Using the transformers library in Python, you can load and use the politicalBiasBERT model for text classification tasks. Here is an example:

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer

model_name = "bucketresearch/politicalBiasBERT"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name)

text = "This article is clearly biased towards a particular political ideology."
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)
```
