# Model name

cross-encoder/nli-distilroberta-base

## Links

- [Hugging Face Model Page](https://huggingface.co/cross-encoder/nli-distilroberta-base)

## Description

The cross-encoder/nli-distilroberta-base model is a fine-tuned version of the DistilRoBERTa-base model trained for natural language inference (NLI) tasks. It is based on the distilroberta-base architecture and uses the transformers library in Python. The model is specifically designed for zero-shot classification tasks and performs well in various evaluation metrics such as accuracy. It has been trained on datasets like multi_nli and snli. The model has approximately 69 million parameters and is licensed under Apache-2.0.

## Usage example

```python
from transformers import AutoTokenizer, AutoModel

tokenizer = AutoTokenizer.from_pretrained("cross-encoder/nli-distilroberta-base")
model = AutoModel.from_pretrained("cross-encoder/nli-distilroberta-base")
```
