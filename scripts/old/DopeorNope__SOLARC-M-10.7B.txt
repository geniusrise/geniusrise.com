# Model name
SOLARC-M-10.7B

## Links
- Original huggingface page: [SOLARC-M-10.7B](https://huggingface.co/DopeorNope/SOLARC-M-10.7B)

## Description
SOLARC-M-10.7B is a language model trained on the Transformers library. It is a part of the transformers pipeline for text generation. The model has been trained using the Llama architecture and is compatible with autotrain and inference endpoints. It has been fine-tuned for text generation tasks and supports the Korean language. The model has a total of 10.7 billion parameters. The license for the model is cc-by-nc-sa-4.0.

## Usage example
```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("DopeorNope/SOLARC-M-10.7B")
model = AutoModelForCausalLM.from_pretrained("DopeorNope/SOLARC-M-10.7B")

inputs = tokenizer.encode("Input text", return_tensors="pt")
outputs = model.generate(inputs)
decoded_outputs = tokenizer.decode(outputs[0])

print(decoded_outputs)
```

Please note that you will need to have the Transformers library installed to use this model.
