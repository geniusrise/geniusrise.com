## Description

The kobart-news model is a Korean BART (Bidirectional and AutoRegressive Transformers) model fine-tuned for news summarization tasks. It is implemented using the transformers library in Python. The model has been trained on a large dataset and can generate abstractive summaries of text based on the input. It has a total of 1626 downloads and has been liked by 16 users. The model is based on the PyTorch library.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("ainize/kobart-news")
model = AutoModelForSeq2SeqLM.from_pretrained("ainize/kobart-news")

input_text = "Sample input text"
inputs = tokenizer(input_text, return_tensors="pt")
outputs = model.generate(inputs["input_ids"])

summary = tokenizer.decode(outputs[0])
print(summary)
```
