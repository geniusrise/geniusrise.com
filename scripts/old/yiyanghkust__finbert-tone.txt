## Description

The finbert-tone model is a text classification model trained using the transformers library in Python. It is designed for financial sentiment analysis and sentiment analysis tasks. The model utilizes the BertForSequenceClassification architecture and is available for both PyTorch and TensorFlow frameworks. It has a total of 11 tags including text-classification, transformers, pytorch, tf, financial-sentiment-analysis, and sentiment-analysis. The model is compatible with AutoTrain and inference endpoints.

The model provides example code and documentation on the Hugging Face model page for usage with the transformers library.

## Usage example

Here is an example of how to use the finbert-tone model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

# Load tokenizer and model
tokenizer = AutoTokenizer.from_pretrained("yiyanghkust/finbert-tone")
model = AutoModelForSequenceClassification.from_pretrained("yiyanghkust/finbert-tone")

# Tokenize input text
text = "growth is strong and we have plenty of liquidity"
inputs = tokenizer(text, truncation=True, return_tensors="pt")

# Perform inference
outputs = model(**inputs)

# Get predicted label
predicted_label = outputs.logits.argmax().item()

# Print predicted label
print(predicted_label)
```

Note that the above example assumes you have already installed the transformers library. You can find more details and examples on the [finbert-tone model page](https://huggingface.co/yiyanghkust/finbert-tone).
