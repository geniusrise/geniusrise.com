## Description
The Llama-2-7B-Chat-GPTQ model is a text generation model created by TheBloke. It is built using the Transformers library and is based on the Llama-2-7B-Chat model provided by Meta Llama 2. The model is trained on a large dataset and has been fine-tuned for chat-based text generation.

This model is particularly useful for generating informative and helpful responses while maintaining safety and ethical considerations. It has been trained to avoid generating harmful, unethical, or illegal content.

The model's architecture is LlamaForCausalLM and it falls under the pipeline tag of text generation. It has a prompt template that can be used to guide its responses.

The model is quantized using the GPTQ (GPT Quantization) method, with 4-bit precision and a group size of 128. The quantization has been done by TheBloke.

The model has been downloaded 126,254 times and has received 213 likes.

## Usage example
Here's an example of how to use the Llama-2-7B-Chat-GPTQ model with the Transformers library in Python:

```python
from transformers import LlamaForCausalLM, LlamaTokenizer

model_name = "TheBloke/Llama-2-7B-Chat-GPTQ"
model = LlamaForCausalLM.from_pretrained(model_name)
tokenizer = LlamaTokenizer.from_pretrained(model_name)

input_prompt = "Hello, how can I help you today?"

input_ids = tokenizer.encode(input_prompt, return_tensors="pt")
outputs = model.generate(input_ids)

generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```
