# Model name

tapas-base-finetuned-sqa

## Links

- [Hugging Face Model Page](https://huggingface.co/google/tapas-base-finetuned-sqa)

## Description

The tapas-base-finetuned-sqa model is a table question answering model based on the Tapas architecture. It has been fine-tuned on the SQA dataset. The model is available in the transformers library with implementations in Python.

The model has a total of 348 million parameters. The architecture is specifically designed for table question answering tasks and supports the extraction of answers from tabular data. It leverages the GPTQ and AWQ algorithms, which are powerful techniques for natural language processing and question answering.

## Usage example

Here is an example of how to use the tapas-base-finetuned-sqa model with the transformers library in Python:

```python
from transformers import TapasForQuestionAnswering, TapasTokenizer

model_name = "google/tapas-base-finetuned-sqa"
model = TapasForQuestionAnswering.from_pretrained(model_name)
tokenizer = TapasTokenizer.from_pretrained(model_name)

# Example table and question
table = [["Name", "Age", "City"], ["John", "25", "New York"], ["Emily", "32", "San Francisco"]]
question = "How old is John?"

inputs = tokenizer(table=table, queries=question, padding="max_length", truncation=True, return_tensors="pt")
outputs = model(**inputs)
answer_coordinates = outputs.answer_coordinates[0]
answer_text = outputs.answer_text[0]

print(f"Answer coordinates: {answer_coordinates}")
print(f"Answer text: {answer_text}")
```

Please refer to the [original huggingface page](https://huggingface.co/google/tapas-base-finetuned-sqa) for more information and usage details.
