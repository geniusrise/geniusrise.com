## Description

The cardiffnlp/twitter-roberta-base-irony model is a base model for text classification tasks using RoBERTa. It is specifically trained for irony detection in Twitter data. The model is fine-tuned on the tweet_eval dataset for English language, and it belongs to the text-classification pipeline of the Transformers library.

The model has been downloaded 8,487,698 times and is liked by 15 users. It has been last modified on August 2nd, 2023. The model supports inference and can be used for tasks related to text classification.

## Usage example

You can use the cardiffnlp/twitter-roberta-base-irony model with the Transformers library in Python. Here is an example of how to use it:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained('cardiffnlp/twitter-roberta-base-irony')
model = AutoModelForSequenceClassification.from_pretrained('cardiffnlp/twitter-roberta-base-irony')

text = "I can't believe how amazing this is!"
input_ids = tokenizer.encode(text, truncation=True, padding=True, return_tensors='pt')
outputs = model(input_ids)
```
