# Model name

google/pegasus-x-base

## Links

- [Hugging Face Model Page](https://huggingface.co/google/pegasus-x-base)

## Description

The `google/pegasus-x-base` model is a Pegasus model developed by Google. Pegasus is a state-of-the-art text-to-text transfer transformer for conditional generation tasks. This model is based on the Pegasus architecture and is trained on a large corpus of data to generate high-quality summaries for various input texts. It can be used for tasks like text summarization, abstractive summarization, and other related tasks. 

The model uses the transformers library with Python for implementation. It has a significant number of parameters and is well-suited for generating high-quality summaries.

## Usage example

```python
from transformers import PegasusTokenizer, PegasusForConditionalGeneration

tokenizer = PegasusTokenizer.from_pretrained("google/pegasus-x-base")
model = PegasusForConditionalGeneration.from_pretrained("google/pegasus-x-base")

input_text = "This is an example sentence that needs to be summarized."
inputs = tokenizer([input_text], truncation=True, padding="longest")
summary_ids = model.generate(inputs.input_ids, num_beams=4, max_length=100)

summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
print(summary)
```

This example shows how to use the `google/pegasus-x-base` model to generate a summary for an input sentence using the transformers library in Python.
