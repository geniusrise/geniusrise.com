# Model name

Mistral-7B-Code-16K-qlora-GPTQ

## Links

- [Model Page](https://huggingface.co/TheBloke/Mistral-7B-Code-16K-qlora-GPTQ)

## Description

Mistral-7B-Code-16K-qlora-GPTQ is a GPT-style language model pretrained on code, specifically for Python. It has 7 billion parameters and uses a tokenization method known as qLoRA (Quantized Layers of Representative Activation) with 4-bit precision. This model is based on the Mistral architecture and is trained on a dataset of 16K Python files.

## Usage example

```python
from transformers import TFGPT2LMHeadModel, GPT2Tokenizer

tokenizer = GPT2Tokenizer.from_pretrained("TheBloke/Mistral-7B-Code-16K-qlora-GPTQ")
model = TFGPT2LMHeadModel.from_pretrained("TheBloke/Mistral-7B-Code-16K-qlora-GPTQ")

input_text = "def calculate_sum(a, b):\n    return a + b\n\nprint(calculate_sum(2, 3))"

input_ids = tokenizer.encode(input_text, return_tensors="tf")
output = model.generate(input_ids)

output_text = tokenizer.decode(output[0])
print(output_text)
```
