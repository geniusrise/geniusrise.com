# Model name

tapas-tiny-finetuned-wtq

## Links

- [Hugging Face Model Page](https://huggingface.co/google/tapas-tiny-finetuned-wtq)

## Description

The `tapas-tiny-finetuned-wtq` model is a fine-tuned version of the Tapas model on the WikiTableQuestions (WTQ) dataset. Tapas is a model for table question answering, specifically designed to understand complex questions that require logical reasoning over table data. This model is trained on a smaller version of Tapas and is suitable for quick prototyping and inference on device.

This model can be used with the `transformers` library in Python. It has a total of 41.4 million parameters.

## Usage example

```python
from transformers import TapasTokenizer, TapasForQuestionAnswering

tokenizer = TapasTokenizer.from_pretrained("google/tapas-tiny-finetuned-wtq")
model = TapasForQuestionAnswering.from_pretrained("google/tapas-tiny-finetuned-wtq")

...
# Use tokenizer and model for inference
...
```
