## Description

The sileod/deberta-v3-large-tasksource-nli model is a variant of the DeBERTa v3 large model trained on various Natural Language Inference (NLI) datasets. It is designed for performing text classification tasks and is based on the transformers library in Python.

The model has been fine-tuned on several datasets, including GLUE, SuperGLUE, ANLI, MetaEval/Babi-NLI, SICK, SNLI, SciTail, and HANS. It has a total of 463 million parameters and is capable of performing zero-shot classification using the zero-shot-classification pipeline. It supports the English language.

## Usage example

You can use the sileod/deberta-v3-large-tasksource-nli model with the transformers library in Python. Here is an example of how to use it for text classification:

```python
from transformers import DebertaForSequenceClassification, DebertaTokenizer

model_name = "sileod/deberta-v3-large-tasksource-nli"
model = DebertaForSequenceClassification.from_pretrained(model_name)
tokenizer = DebertaTokenizer.from_pretrained(model_name)

text = "This is an example sentence."
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)

logits = outputs.logits
predicted_label = torch.argmax(logits, dim=1).item()
```
