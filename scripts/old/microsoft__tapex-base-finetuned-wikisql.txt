## Description

The `microsoft/tapex-base-finetuned-wikisql` model is a table question-answering model based on the BART architecture. It has been fine-tuned on the WikiSQL dataset. This model is part of the TAPeX project, which focuses on table pre-training.

The model can be used for various NLP tasks related to table question answering, such as summarization and generation.

Key features of the model include:
- Language: English
- Tags: transformers, pytorch, bart, text2text-generation, tapex, table-question-answering, en, dataset:wikisql, arxiv:2107.07653, license:mit
- Datasets: WikiSQL
- Number of parameters: Not specified

The model can be accessed and used through the transformers library in Python.

## Usage example

```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model_name = "microsoft/tapex-base-finetuned-wikisql"
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

text = "How many stars does the transformers repository have?"
inputs = tokenizer(text, return_tensors="pt")
outputs = model.generate(inputs["input_ids"])

generated_text = tokenizer.decode(outputs[0])
print(generated_text)
```

This example demonstrates how to use the `microsoft/tapex-base-finetuned-wikisql` model for table question answering. The model is loaded using `AutoModelForSeq2SeqLM`, and the text to be answered is tokenized using `AutoTokenizer`. The generated answer is then decoded and printed.
