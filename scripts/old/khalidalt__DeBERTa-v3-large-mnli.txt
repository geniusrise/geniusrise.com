# Model name

khalidalt/DeBERTa-v3-large-mnli

## Links

- [Original Hugging Face page](https://huggingface.co/khalidalt/DeBERTa-v3-large-mnli)

## Description

The khalidalt/DeBERTa-v3-large-mnli model is a text classification model based on the DeBERTa-v3-large architecture. It is primarily designed for the task of text classification, specifically for the Multi-Genre Natural Language Inference (MNLI) task. It has been fine-tuned on the MNLI dataset and achieves high accuracy.

The model is implemented using the transformers library in Python and is compatible with PyTorch. It has a total of 502 million parameters. The model is trained to understand the relationships between different sentences and can be used for various applications such as sentiment analysis, spam detection, and intent classification.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("khalidalt/DeBERTa-v3-large-mnli")
model = AutoModelForSequenceClassification.from_pretrained("khalidalt/DeBERTa-v3-large-mnli")

# Tokenize input text
inputs = tokenizer("The movie has been criticized for the story. However, I think it is a great movie. [SEP] I liked the movie.", return_tensors="pt")

# Classify text
outputs = model(**inputs)
predictions = outputs.logits.argmax(dim=1)

print(predictions)
```

Note: Make sure to install the transformers library before running the code.
