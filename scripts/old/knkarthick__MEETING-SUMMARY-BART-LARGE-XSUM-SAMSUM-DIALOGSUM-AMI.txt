# Model name

knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI

## Links

[Original Hugging Face Page](https://huggingface.co/knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI)

## Description

The knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI model is a BART-based model trained to summarize meeting conversations. It is trained on large-scale summarization datasets like XSum, SAMSum, DialogSum, and AMI. The model is fine-tuned on the BART-LARGE architecture and is capable of generating abstractive summaries of meeting dialogues.

The model has been evaluated using the ROUGE metric and performs well on various summarization tasks. It is available for use through the Transformers library in Python.

The model is licensed under Apache-2.0.

## Usage example

```python
from transformers import pipeline

summarization = pipeline("summarization", model="knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI")

texts = [
    "Hi, I'm David and I'm supposed to be an industrial designer. Um, I just got the project announcement about what the project is...",
    "Okay. Right. Um well this is the kick-off meeting for our our project. Um and um this is just what we're gonna be doing over the next twenty five minutes..."
]

summaries = summarization(texts, max_length=150, min_length=30)

for summary in summaries:
    print(summary["summary_text"])
```

This code snippet demonstrates how to use the knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI model to generate summaries of meeting conversations. The pipeline function from the Transformers library is used to set up the summarization task. The model is then applied to a list of texts, with maximum and minimum length constraints for the generated summaries. The resulting summaries are printed to the console.
