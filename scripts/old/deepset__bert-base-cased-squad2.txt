# Model name
deepset/bert-base-cased-squad2

## Links

## Description
The `deepset/bert-base-cased-squad2` model is a fine-tuned version of the BERT (Base, Cased) model for the question-answering task. It is trained on the SQuAD v2.0 dataset, which includes questions and answers from a variety of domains. The model is available in the transformers library with Python.

This model has a total of 108,311,810 parameters. It achieves an exact match score of 71.15% and an F1 score of 74.67% on the SQuAD v2.0 validation dataset.

## Usage example
Here's an example of using the `deepset/bert-base-cased-squad2` model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForQuestionAnswering

tokenizer = AutoTokenizer.from_pretrained("deepset/bert-base-cased-squad2")
model = AutoModelForQuestionAnswering.from_pretrained("deepset/bert-base-cased-squad2")

text = "The earth revolves around the sun."
question = "What does the earth revolve around?"

inputs = tokenizer.encode_plus(question, text, add_special_tokens=True, return_tensors="pt")
input_ids = inputs["input_ids"].tolist()[0]
outputs = model(**inputs)

start_index = torch.argmax(outputs.start_logits)
end_index = torch.argmax(outputs.end_logits) + 1
answer = tokenizer.convert_tokens_to_string(tokenizer.convert_ids_to_tokens(input_ids[start_index:end_index]))

print("Answer:", answer)
```

Note: Make sure to install the transformers library with `pip install transformers`.
