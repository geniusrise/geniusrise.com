## Description

The Nous-Hermes-2-Yi-34B model is a text generation model trained by NousResearch. It uses the LlamaForCausalLM architecture and is based on the base model 01-ai/Yi-34B. The model is fine-tuned using synthetic data and distillation techniques. It is compatible with the transformers library and supports text generation tasks.

The model has been downloaded 9511 times and has received 155 likes. It is tagged with labels such as "text-generation," "transformers," "llama," and "yi." The model is publicly available and licensed under Apache 2.0.

For more details, refer to the [Hugging Face Model Card](https://huggingface.co/NousResearch/Nous-Hermes-2-Yi-34B).

## Usage example

Here is an example of how to use the Nous-Hermes-2-Yi-34B model with the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "NousResearch/Nous-Hermes-2-Yi-34B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=100, do_sample=True)
decoded_output = tokenizer.decode(output[0])

print(decoded_output)
```

Make sure to install the transformers library before running the code.
