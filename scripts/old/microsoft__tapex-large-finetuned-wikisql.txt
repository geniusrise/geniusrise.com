## Description
The microsoft/tapex-large-finetuned-wikisql model is a large-scale language model that has been fine-tuned on the WikiSQL dataset. It is based on the BART (Bidirectional and Auto-Regressive Transformers) architecture and is part of the transformers library. This model is specifically designed for table question answering tasks.

Key features and details of the model:
- Number of parameters: Not specified
- Compatible with the transformers library and PyTorch
- Supports table question answering in English using the WikiSQL dataset

For more details, please visit the [Hugging Face Model Page](https://huggingface.co/microsoft/tapex-large-finetuned-wikisql).

## Usage example
You can use the microsoft/tapex-large-finetuned-wikisql model with the transformers library in Python. Here is an example of how to use it:

```python
from transformers import TapexForConditionalGeneration, TapexTokenizer

model_name = "microsoft/tapex-large-finetuned-wikisql"
tokenizer = TapexTokenizer.from_pretrained(model_name)
model = TapexForConditionalGeneration.from_pretrained(model_name)

# Example input
input_text = "What is the average population of each city in the table?"

# Tokenize input
input_ids = tokenizer.encode(input_text, return_tensors="pt")

# Generate table question answering output
output = model.generate(input_ids)

# Decode output
decoded_output = tokenizer.decode(output[0])

print(decoded_output)
```

Please note that the above example code is just a basic demonstration and may require additional preprocessing and postprocessing steps depending on your specific use case.
