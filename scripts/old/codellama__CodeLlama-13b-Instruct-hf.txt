# Model name

CodeLlama-13b-Instruct-hf

## Links

- [Hugging Face Model Page](https://huggingface.co/codellama/CodeLlama-13b-Instruct-hf)

## Description

CodeLlama-13b-Instruct-hf is a text generation model trained by Code Llama. It is built using the transformers library with Python. The model is designed for instructing text generation tasks. It has a language pipeline tag of "text-generation" and is compatible with the AutoModelForCausalLM architecture. The model has been trained on a variety of datasets and has a total of 13 billion parameters. It is part of the Code Llama project and is licensed under llama2.

## Usage example

Here's an example of how to use the CodeLlama-13b-Instruct-hf model with the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "codellama/CodeLlama-13b-Instruct-hf"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Write a Python function to add two numbers."
encoded_input = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(encoded_input)

decoded_output = tokenizer.decode(output[0])

print(decoded_output)
```

Note that you will need to have the transformers library installed to use the model.
