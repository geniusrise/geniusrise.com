# Model name

Llama-2-13b-chat-hf

## Links

- [Hugging Face Model Page](https://huggingface.co/meta-llama/Llama-2-13b-chat-hf)

## Description

Llama-2-13b-chat-hf is a text generation model that belongs to the Llama-2 series. It is available on the Hugging Face model hub. This model is based on the LlamaForCausalLM architecture and is fine-tuned for chat-like dialogues. It is implemented using the transformers library in Python.

The model has a total of 13 billion parameters, making it a large-scale language model. It is trained on a wide range of datasets, and it supports English language text generation.

This model is part of the Llama project, which aims to advance and democratize artificial intelligence through open-source and open science approaches. 

## Usage example

Here is an example of how to use the Llama-2-13b-chat-hf model with the transformers library in Python:

```python
from transformers import GPT2Tokenizer, GPT2LMHeadModel

tokenizer = GPT2Tokenizer.from_pretrained('meta-llama/Llama-2-13b-chat-hf')
model = GPT2LMHeadModel.from_pretrained('meta-llama/Llama-2-13b-chat-hf')

input_text = "Hello, how are you?"
input_ids = tokenizer.encode(input_text, return_tensors='pt')

output = model.generate(input_ids, max_length=100)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```
