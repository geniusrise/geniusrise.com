# Model name

MistralLite

## Links

- [Hugging Face Model Page](https://huggingface.co/amazon/MistralLite)

## Description

MistralLite is a text generation model developed by Amazon Web Services. It is based on the Mistral architecture and is compatible with the Transformers library in Python. The model is designed for text generation tasks and is particularly suited for tasks such as summarization, translation, and dialogue generation. The model has been trained on large-scale datasets and has a relatively small number of parameters. It is available for public use and can be accessed through the Hugging Face model page.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "amazon/MistralLite"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Once upon a time,"
inputs = tokenizer(input_text, return_tensors="pt")
outputs = model.generate(inputs["input_ids"])

generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```

Please refer to the [Hugging Face Model Page](https://huggingface.co/amazon/MistralLite) for more details and examples.
