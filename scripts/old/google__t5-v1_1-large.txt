# Model name

t5-v1_1-large

## Links

- [Hugging Face Model Page](https://huggingface.co/google/t5-v1_1-large)

## Description

The t5-v1_1-large model is a transformer-based language model developed by Google. It belongs to the T5 family of models and is powered by the Transformers library. The model is designed for text-to-text generation tasks and has been trained on various datasets, including the C4 dataset. It has a total of 770 million parameters and supports inference.

## Usage Example

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/t5-v1_1-large")
model = T5ForConditionalGeneration.from_pretrained("google/t5-v1_1-large")

input_text = "Translate this English sentence to French: 'Hello, how are you?'"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output_ids = model.generate(input_ids)
output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)

print(output_text)
```

Output: "Bonjour, comment ça va ?"
