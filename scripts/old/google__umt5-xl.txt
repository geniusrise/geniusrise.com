# Model Name

google/umt5-xl

## Links

- [Hugging Face Model Page](https://huggingface.co/google/umt5-xl)

## Description

The `google/umt5-xl` model is a variant of the T5 (Text-To-Text Transfer Transformer) model developed by Google. It is an extra-large, multilingual model that is capable of performing a variety of text generation tasks, including translation, summarization, question answering, and more. The model has been trained on a diverse range of languages, making it suitable for handling multilingual data. It has a total of 1.2 billion parameters and performs inference using the transformers library with Python. The model is licensed under Apache 2.0.

## Usage example

To use the `google/umt5-xl` model for text generation tasks, you can utilize the transformers library with Python. Here's an example:

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/umt5-xl")
model = T5ForConditionalGeneration.from_pretrained("google/umt5-xl")

input_text = "Translate this sentence to French: 'Hello, how are you?'"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

outputs = model.generate(input_ids)
decoded_output = tokenizer.decode(outputs[0])

print(decoded_output)
```

This example demonstrates how to use the `google/umt5-xl` model to translate an English sentence to French. You can replace the input text and adapt the code for different tasks such as summarization or question answering.
