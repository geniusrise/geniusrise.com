# Model name

WizardMath-70B-V1.0-GPTQ

## Links

- [Hugging Face Model Card](https://huggingface.co/TheBloke/WizardMath-70B-V1.0-GPTQ)

## Description

The WizardMath-70B-V1.0-GPTQ model is a large-scale language model trained using the Llama framework. It is based on the WizardLM/WizardMath-70B-V1.0 base model and is fine-tuned for the task of text generation. The model is aimed at empowering mathematical reasoning and can generate responses to instructions that require step-by-step reasoning. It has a total of approximately 9.1 billion trainable parameters and supports 4-bit quantization. The model is compatible with the transformers library in Python.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("TheBloke/WizardMath-70B-V1.0-GPTQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/WizardMath-70B-V1.0-GPTQ")

# Example text generation using the model
prompt = "Below is an instruction that describes a task. Write a response that appropriately completes the request.\n\n\n### Instruction:\nSolve the following equation:\n2x + 5 = 15\n\n\n### Response: Let's think step by step."
inputs = tokenizer.encode(prompt, return_tensors="pt")
outputs = model.generate(inputs, max_length=100)

generated_text = tokenizer.decode(outputs[0])
print(generated_text)
```
