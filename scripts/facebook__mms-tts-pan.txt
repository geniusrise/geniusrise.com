## Description

The Massively Multilingual Speech (MMS): Punjabi, Eastern Text-to-Speech (TTS) model is part of Facebook's Massively Multilingual Speech project, which aims to provide speech technology across a diverse range of languages. This specific model is trained on the Punjabi, Eastern language. It is an end-to-end speech synthesis model that predicts a speech waveform based on an input text sequence. The model consists of a posterior encoder, decoder, and conditional prior, and uses a set of spectrogram-based acoustic features predicted by a flow-based module. The model also includes a stochastic duration predictor to allow for varied speech rhythms from the same input text. It is trained using a combination of variational lower bound and adversarial training losses.

The MMS-TTS model is available in the 🤗 Transformers library from version 4.33 onwards. It can be used to generate synthetic speech in the Punjabi, Eastern language.

## Usage example

```python
from transformers import VitsModel, AutoTokenizer
import torch

model = VitsModel.from_pretrained("facebook/mms-tts-pan")
tokenizer = AutoTokenizer.from_pretrained("facebook/mms-tts-pan")

text = "some example text in the Punjabi, Eastern language"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    output = model(**inputs).waveform
```

The resulting waveform can be saved as a .wav file or displayed in a Jupyter Notebook / Google Colab.
