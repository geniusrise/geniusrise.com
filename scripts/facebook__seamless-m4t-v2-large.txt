## Description

SeamlessM4T v2 is an all-in-one Massively Multilingual and Multimodal Machine Translation model developed by Facebook. It delivers high-quality translation for both speech and text in nearly 100 languages. The model supports various tasks, including speech-to-speech translation (S2ST), speech-to-text translation (S2TT), text-to-speech translation (T2ST), text-to-text translation (T2TT), and automatic speech recognition (ASR). SeamlessM4T v2 is built on the novel UnitY2 architecture, which improves both the quality and inference speed of speech generation tasks compared to the previous version, SeamlessM4T v1.

The SeamlessM4T v2 model is available in two sizes: SeamlessM4T-Large v2 (2.3 billion parameters) and SeamlessM4T-Medium v2 (1.2 billion parameters). The evaluation results of SeamlessM4T-Large and SeamlessM4T-Medium models are provided in the metrics files.

The model is supported by the 🤗 Transformers library, making it easy to integrate and use with minimal dependencies.

## Usage example

```python
# Install the 🤗 Transformers library and sentencepiece
pip install git+https://github.com/huggingface/transformers.git sentencepiece

# Import necessary libraries
from transformers import AutoProcessor, SeamlessM4Tv2Model
import torchaudio

# Load the processor and model
processor = AutoProcessor.from_pretrained("facebook/seamless-m4t-v2-large")
model = SeamlessM4Tv2Model.from_pretrained("facebook/seamless-m4t-v2-large")

# Translate text to Russian
text_inputs = processor(text="Hello, my dog is cute", src_lang="eng", return_tensors="pt")
audio_array_from_text = model.generate(**text_inputs, tgt_lang="rus")[0].cpu().numpy().squeeze()

# Translate audio to Russian
audio, orig_freq = torchaudio.load("https://www2.cs.uic.edu/~i101/SoundFiles/preamble10.wav")
audio = torchaudio.functional.resample(audio, orig_freq=orig_freq, new_freq=16_000)  # must be a 16 kHz waveform array
audio_inputs = processor(audios=audio, return_tensors="pt")
audio_array_from_audio = model.generate(**audio_inputs, tgt_lang="rus")[0].cpu().numpy().squeeze()
```

The above code demonstrates how to use the SeamlessM4T v2 model for speech translation. It includes examples for translating text from English to Russian and translating audio from a provided URL to Russian. The generated output can be listened to or saved as a .wav file using third-party libraries like scipy.

## Business Use Cases

SeamlessM4T v2 can be used in various business scenarios, including:

1. Multilingual Customer Support: The model can be utilized to provide real-time translation of customer queries and responses in multiple languages, enabling seamless communication between customer support agents and customers who speak different languages.

2. Global Content Localization: Businesses operating internationally can leverage the model to translate their content, such as websites, product descriptions, and marketing materials, into different languages. This enables them to effectively reach and engage with customers from various regions.

3. Multilingual Communication in Meetings: For multinational companies, the model can facilitate multilingual communication during meetings and conferences. It can automatically translate speech to text, allowing participants to comprehend discussions in their preferred language, regardless of the language spoken by the speakers.

4. Language Learning and Education: The SeamlessM4T v2 model can be used to develop language learning platforms and educational tools. It can provide translations, transcriptions, and pronunciation assistance to learners, helping them improve their language skills and overcome language barriers.

5. Accessibility for the Hearing Impaired: With its support for speech-to-text translation, the model can be employed to enhance accessibility for individuals with hearing impairments. It can convert spoken language into text, enabling hearing-impaired individuals to read and understand conversations, presentations, or audiovisual content.

These are just a few examples of how businesses can utilize the SeamlessM4T v2 model to overcome language barriers and enhance communication and accessibility in various domains.
