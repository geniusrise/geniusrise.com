## Description

The SauerkrautLM Una SOLAR Instruct - AWQ is a language model created by Yağız Çalık and adapted for low-bit weight quantization by TheBloke using the AWQ method. AWQ is an accurate and CPU-efficient 4-bit quantization method providing faster inference speed compared to most popular GPTQ settings.

The model has been further merged using the MergeKit method, combining models to get the best performance from their features. The SauerkrautLM-UNA-SOLAR-Instruct version of this model is quantized using AWQ, making it an optimized transformer model for GPU inference on Linux and Windows systems.

## Usage Example

Using Transformers library:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TextStreamer

model_name_or_path = "TheBloke/SauerkrautLM-UNA-SOLAR-Instruct-AWQ"

tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)

model = AutoModelForCausalLM.from_pretrained(
    model_name_or_path,
    low_cpu_mem_usage=True,
    device_map="cuda:0"
)

# Apply text streaming for generating output token by token
streamer = TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)

prompt = "Tell me about AI"
prompt_template=f'''### User:
{prompt}

### Assistant:
''' 

tokens = tokenizer(prompt_template, return_tensors='pt').input_ids.cuda()

generation_params = {
    "do_sample": True,
    "temperature": 0.7,
    "top_p": 0.95,
    "top_k": 40,
    "max_new_tokens": 512,
    "repetition_penalty": 1.1
}

# Generate responses with the model
generation_output = model.generate(tokens, streamer=streamer, **generation_params)

token_output = generation_output[0]
text_output = tokenizer.decode(token_output)
print("model.generate output: ", text_output)
```
