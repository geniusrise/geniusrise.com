## Description

Mixtral 8X7B Instruct v0.1 is an efficient and fast low-bit weight quantization method developed by Mistral AI. It is currently supporting 4-bit quantization. The model is based on the original Mixtral 8X7B Instruct model, which is a pretrained generative Sparse Mixture of Experts (LLM). The Mixtral 8X7B Instruct v0.1 has been finely tuned to achieve compelling performance and outperforms similar models across various benchmarks that it has been tested on.

This model utilizes an accuracy-weighted quantization method (AWQ), offering faster Transformers-based inference with equivalent or better quality than most commonly used GPTQ settings. The model is compatible with Linux and Windows, and for use with NVidia GPUs. 

The instruction format of the model frames a user's input within [INST] and [/INST] tags. This formatting must be strictly followed to achieve the best output results.

## Usage example

### Using Transformers Library in Python

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name_or_path = "TheBloke/Mixtral-8x7B-Instruct-v0.1-AWQ"
tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)

model = AutoModelForCausalLM.from_pretrained(
    model_name_or_path,
    low_cpu_mem_usage=True,
    device_map="cuda:0"
)

prompt = "Tell me about AI"
prompt_template=f'''[INST] {prompt} [/INST]'''

tokens = tokenizer(
    prompt_template,
    return_tensors='pt'
).input_ids.cuda()

generation_params = {
    "do_sample": True,
    "temperature": 0.7,
    "top_p": 0.95,
    "top_k": 40,
    "max_new_tokens": 512,
    "repetition_penalty": 1.1
}

generation_output = model.generate(
    tokens,
    **generation_params
)

token_output = generation_output[0]
text_output = tokenizer.decode(token_output)
print("model.generate output: ", text_output)
```
