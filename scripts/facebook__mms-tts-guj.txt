# Model name

Massively Multilingual Speech (MMS): Gujarati Text-to-Speech

## Links

- [Hugging Face Model Page](https://huggingface.co/facebook/mms-tts-guj)
- [GitHub Repository](https://github.com/facebookresearch/multilingual-speech)

## Description

The MMS-TTS (Massively Multilingual Speech) model is a Gujarati (guj) language text-to-speech (TTS) model checkpoint developed as part of Facebook's Massively Multilingual Speech project. It is an end-to-end speech synthesis model based on the VITS (Variational Inference with adversarial learning for end-to-end Text-to-Speech) architecture. The model generates speech waveforms given an input text sequence. It incorporates a Transformer-based text encoder, a flow-based module to predict acoustic features, a duration predictor to synthesize speech with different rhythms, and a HiFi-GAN vocoder for waveform decoding. The model is trained with a combination of variational lower bound and adversarial training losses. The MMS-TTS model is available in the 🤗 Transformers library from version 4.33 onwards.

## Usage example

To use the MMS-TTS model, follow these steps:

1. Install the latest version of the 🤗 Transformers library:
    ```
    pip install --upgrade transformers accelerate
    ```

2. Import the necessary modules and load the model checkpoint and tokenizer:
    ```python
    from transformers import VitsModel, AutoTokenizer
    import torch

    model = VitsModel.from_pretrained("facebook/mms-tts-guj")
    tokenizer = AutoTokenizer.from_pretrained("facebook/mms-tts-guj")
    ```

3. Prepare the input text and encode it using the tokenizer:
    ```python
    text = "some example text in the Gujarati language"
    inputs = tokenizer(text, return_tensors="pt")
    ```

4. Generate the speech waveform:
    ```python
    with torch.no_grad():
        output = model(**inputs).waveform
    ```

5. Optionally, save the waveform as a .wav file:
    ```python
    import scipy

    scipy.io.wavfile.write("techno.wav", rate=model.config.sampling_rate, data=output)
    ```

6. Optionally, display the waveform in a Jupyter Notebook or Google Colab:
    ```python
    from IPython.display import Audio

    Audio(output, rate=model.config.sampling_rate)
    ```

The MMS-TTS model supports generating speech in the Gujarati language. For more information, refer to the [Hugging Face Model Page](https://huggingface.co/facebook/mms-tts-guj).

## Use Cases

The MMS-TTS model can be used for various business applications, including:

1. **Multilingual Voice Assistants:** The model can be integrated into voice assistant applications to generate natural-sounding speech in Gujarati, enabling users to interact with the assistant using their native language.

2. **Audiobook Generation:** Publishers can utilize the model to convert written content into spoken audio, enabling the creation of audiobooks in Gujarati.

3. **Accessibility Services:** The model can be used to provide text-to-speech capabilities for visually impaired individuals, allowing them to listen to written content in Gujarati.

4. **Language Learning and Pronunciation Training:** Language learning platforms can leverage the model to generate audio for language lessons and pronunciation exercises in Gujarati, enhancing the learning experience for learners.

5. **Interactive Voice Response (IVR) Systems:** The model can be integrated into IVR systems to provide personalized and natural-sounding voice prompts and responses in Gujarati for customer service and call center applications.

These are just a few examples of how the MMS-TTS model can be utilized for business use cases. The model's flexibility and ability to generate speech in Gujarati make it a valuable tool for speech synthesis applications in diverse industries.
