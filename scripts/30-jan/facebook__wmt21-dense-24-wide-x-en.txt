## Description

The facebook/wmt21-dense-24-wide-x-en model is a multilingual neural machine translation model trained by Facebook AI. It is based on the M2M100 architecture and is designed for text-to-text generation tasks with a focus on translation. The model has been fine-tuned for the WMT21 News Translation Task. It supports various languages, including multilingual, Hausa (ha), Icelandic (is), Japanese (ja), Czech (cs), Russian (ru), Chinese (zh), German (de), and English (en). The model is built using the transformers library in Python.

## Usage example

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("facebook/wmt21-dense-24-wide-x-en")
model = T5ForConditionalGeneration.from_pretrained("facebook/wmt21-dense-24-wide-x-en")

text = "Translate this text to French."
inputs = tokenizer.encode(text, return_tensors="pt")
outputs = model.generate(inputs)
translated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)

print(translated_text)
```

Make sure to install the transformers library with `pip install transformers`.
