## Description

The dslim/bert-large-NER model is a BERT-based model trained for token classification tasks, specifically named entity recognition (NER). It is built using the Transformers library and is available in Python. The model has been trained on the CoNLL-2003 dataset and achieves high performance on various metrics such as accuracy, precision, recall, F1 score, and loss.

This model is based on the BERT architecture, which is a transformer-based model pre-trained on a large corpus of text. It is designed to generate contextualized word representations that capture the meaning of words in the context of a sentence.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification

tokenizer = AutoTokenizer.from_pretrained("dslim/bert-large-NER")
model = AutoModelForTokenClassification.from_pretrained("dslim/bert-large-NER")

text = "My name is John Doe and I live in New York."
inputs = tokenizer.encode_plus(text, return_tensors="pt")
outputs = model(**inputs)

predictions = torch.argmax(outputs.logits, dim=2)[0]
labels = [tokenizer.convert_ids_to_tokens(token_id) for token_id in predictions]

print(labels)
```

In the above example, the model is loaded using the `AutoTokenizer` and `AutoModelForTokenClassification` classes from the Transformers library. The input text is encoded, and the model is used to predict the labels for the tokens in the input sequence. The predicted labels are then converted back to their original tokens using the tokenizer.
