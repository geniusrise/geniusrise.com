## Description

The Nous-Hermes-2-Yi-34B model is a text generation model trained using the transformers library with Python. It is built on the 01-ai/Yi-34B base model and is fine-tuned for text generation tasks. The model uses a synthetic dataset and distillation techniques.

Some key features and tags associated with the model are:
- Language: English
- Libraries: transformers, Safetensors
- Architecture: LlamaForCausalLM
- Tags: yi, instruct, finetune, chatml, gpt4, synthetic data, distillation, text-generation, transformers

## Usage example

```python
from transformers import AutoTokenizer, AutoModel

tokenizer = AutoTokenizer.from_pretrained("NousResearch/Nous-Hermes-2-Yi-34B")
model = AutoModel.from_pretrained("NousResearch/Nous-Hermes-2-Yi-34B")

input_text = "Generate a text about dogs."
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

Note: Please make sure you have the transformers library installed before running the code above.
