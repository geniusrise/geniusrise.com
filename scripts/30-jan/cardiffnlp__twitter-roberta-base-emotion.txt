# Model name
twitter-roberta-base-emotion

## Links
- [Model Page](https://huggingface.co/cardiffnlp/twitter-roberta-base-emotion)
- [GitHub Repository](https://github.com/cardiffnlp/twitter-roberta-base-emotion)

## Description
The twitter-roberta-base-emotion model is a text classification model that is based on the RoBERTa architecture. It has been trained on Twitter data to classify the emotion expressed in a tweet. The model is compatible with the Transformers library in Python and can be used for tasks such as sentiment analysis and emotion detection in social media text.

The model has been trained on a large dataset and has a substantial number of parameters. It utilizes the GPTQ framework, which stands for Generative Pretrained Transformer from Question (GPTQ) and aims to provide a comprehensive understanding of the emotions expressed in tweets.

## Usage example
Here is an example of using the twitter-roberta-base-emotion model with the Transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cardiffnlp/twitter-roberta-base-emotion")
model = AutoModelForSequenceClassification.from_pretrained("cardiffnlp/twitter-roberta-base-emotion")

text = "I love this movie!"
encoded_input = tokenizer(text, return_tensors='pt')
output = model(**encoded_input)
```

In this example, the model is loaded using the `from_pretrained` method from the Transformers library. The input text is tokenized using the tokenizer, and then passed through the model for classification. The output consists of the predicted labels for the input text.
