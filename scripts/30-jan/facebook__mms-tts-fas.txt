## Description

MMS-TTS is a text-to-speech model checkpoint for the Persian (fas) language. It is part of Facebook's Massively Multilingual Speech project, which aims to provide speech technology for a diverse range of languages. The model is built using VITS (Variational Inference with adversarial learning for end-to-end Text-to-Speech), an end-to-end speech synthesis model that predicts speech waveforms based on input text sequences. It utilizes a conditional variational autoencoder (VAE), consisting of a posterior encoder, decoder, and conditional prior. The model incorporates a flow-based module, which predicts spectrogram-based acoustic features using a Transformer-based text encoder and multiple coupling layers. The spectrogram is then decoded using transposed convolutional layers similar to the HiFi-GAN vocoder. The model also includes a stochastic duration predictor to accommodate the one-to-many nature of the TTS problem, allowing for speech synthesis with different rhythms from the same input text. During training, a combination of losses derived from variational lower bound and adversarial training is used. Normalizing flows are applied to the conditional prior distribution to enhance model expressiveness. Inference involves up-sampling the text encodings based on the duration prediction module and mapping them into waveforms using the flow module and HiFi-GAN decoder. The model is non-deterministic, requiring a fixed seed to generate consistent speech waveforms. A separate VITS checkpoint is trained for each language in the MMS project.

## Usage example

You can utilize the MMS-TTS model checkpoint using the 🤗 Transformers library. First, ensure that you have the latest version of the library installed:

```
pip install --upgrade transformers accelerate
```

Then, you can run inference with the following code snippet:

```python
from transformers import VitsModel, AutoTokenizer
import torch

model = VitsModel.from_pretrained("facebook/mms-tts-fas")
tokenizer = AutoTokenizer.from_pretrained("facebook/mms-tts-fas")

text = "some example text in the Persian language"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    output = model(**inputs).waveform
```

You can save the resulting waveform as a .wav file:

```python
import scipy

scipy.io.wavfile.write("techno.wav", rate=model.config.sampling_rate, data=output)
```

Alternatively, you can display the waveform in a Jupyter Notebook or Google Colab:

```python
from IPython.display import Audio

Audio(output, rate=model.config.sampling_rate)
```

Please note that the MMS-TTS model requires a fixed seed for consistent speech waveform generation.

## Use Cases

- Language learning applications: The MMS-TTS model can be used to provide text-to-speech capabilities for educational apps, helping users learn pronunciation and develop language skills.
- Accessibility features: This model can be integrated into assistive technologies, such as screen readers, to convert written content into spoken words for visually impaired individuals.
- Voice assistants: The MMS-TTS model can be leveraged to power voice assistants, enabling them to convert textual information into natural-sounding speech responses.
- Audiobook production: Publishers and authors can utilize the MMS-TTS model to create high-quality audiobooks, automating the narration process and reaching a broader audience.
- Call center applications: The model can be used to generate synthetic voices for automated interactive voice response (IVR) systems, enhancing customer experience and reducing costs associated with human voice actors.
