# Model name
TheBloke/Mistral-7B-Code-16K-qlora-GPTQ

- [GitHub Repo](https://github.com/TheBloke/Mistral-7B-Code-16K-qlora-GPTQ)

## Description
The Mistral-7B-Code-16K-qlora-GPTQ model is a text generation model trained using the Mistral architecture. It is fine-tuned on a code completion task with a vocabulary of 16,000 tokens. The model provides instructions and prompts for text generation tasks. It has been quantized using the GPTQ method by TheBloke. The model is available for usage with the transformers library in Python.

## Usage example
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/Mistral-7B-Code-16K-qlora-GPTQ"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

prompt = "Write a Python function to calculate the factorial of a number."
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids, max_length=100)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

Please note that the model has approximately 880,476,160 parameters.
