# Model name

deepset/deberta-v3-large-squad2

## Links

- [Model Page](https://huggingface.co/deepset/deberta-v3-large-squad2)
- [GitHub Repo](https://github.com/deepset-ai/haystack)

## Description

The deepset/deberta-v3-large-squad2 model is a Question Answering model based on the DeBERTa-v3 framework. It has been fine-tuned on the SQuAD v2 dataset. The model has achieved an exact match accuracy of 88.0876% and an F1 score of 91.1623% on the validation set of SQuAD v2. 

This model is compatible with the transformers library in Python.

## Usage example

```python
from transformers import DebertaTokenizer, DebertaForQuestionAnswering
import torch

tokenizer = DebertaTokenizer.from_pretrained("deepset/deberta-v3-large-squad2")
model = DebertaForQuestionAnswering.from_pretrained("deepset/deberta-v3-large-squad2")

question = "What is the capital of France?"
context = "The capital of France is Paris."

inputs = tokenizer.encode_plus(question, context, return_tensors="pt")
start_logits, end_logits = model(**inputs)

start_index = torch.argmax(start_logits)
end_index = torch.argmax(end_logits)

answer_tokens = inputs["input_ids"][0][start_index:end_index+1]
answer = tokenizer.decode(answer_tokens)
print(answer)
```

Please note that this model has a total of 544 million parameters.

For more details, please refer to the [model page](https://huggingface.co/deepset/deberta-v3-large-squad2) and the [GitHub repository](https://github.com/deepset-ai/haystack).
