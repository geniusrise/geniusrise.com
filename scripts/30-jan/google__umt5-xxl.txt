google/umt5-xxl

## Links

- [Model page](https://huggingface.co/google/umt5-xxl)
- [GitHub repository](https://github.com/google-research/mt5)

## Description

The google/umt5-xxl model is part of the T5 family of models by Google Research. It is a multilingual text-to-text transfer transformer model. It is trained on the multi-corpus dataset (mc4), which is a large-scale web document dataset in multiple languages. This model has been fine-tuned for text generation tasks and is capable of performing inference.

The google/umt5-xxl model has a large number of parameters, but the exact number is not mentioned on the model page.

## Usage example

Here is an example of how to use the google/umt5-xxl model with the transformers library in Python:

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/umt5-xxl")
model = T5ForConditionalGeneration.from_pretrained("google/umt5-xxl")

input_text = "Translate this text from English to French."

inputs = tokenizer.encode(input_text, return_tensors="pt")
outputs = model.generate(inputs)

translated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(translated_text)
```

This will output the translated text in French.
