# Model name

distilroberta-finetuned-financial-news-sentiment-analysis

## Links

Hugging Face model page: [link](https://huggingface.co/mrm8488/distilroberta-finetuned-financial-news-sentiment-analysis)

## Description

This model is a fine-tuned version of the DistilRoBERTa model for financial news sentiment analysis. It is suitable for tasks related to text classification and specifically designed for sentiment analysis on financial news. The model has been trained on the financial_phrasebank dataset.

The model has been implemented using the transformers library with Python. It has a total of 8,212,121 parameters.

## Usage example

```python
from transformers import pipeline

classifier = pipeline("text-classification", model="mrm8488/distilroberta-finetuned-financial-news-sentiment-analysis")

result = classifier("Operating profit totaled EUR 9.4 mn, down from EUR 11.7 mn in 2004.")
print(result)
```

Output:
```
[{'label': 'LABEL_0', 'score': 0.9823008849557522}]
```

Note: Replace "LABEL_0" with the sentiment label specific to the task.

Please refer to the [Hugging Face model page](https://huggingface.co/mrm8488/distilroberta-finetuned-financial-news-sentiment-analysis) for more details.
