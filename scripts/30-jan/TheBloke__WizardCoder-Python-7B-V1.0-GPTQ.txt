## Description

WizardCoder-Python-7B-V1.0-GPTQ is a text generation model trained on Python code using the GPTQ variant of the GPT-3 architecture. It has been fine-tuned on the WizardLM dataset and is part of the Wizards series of models. The model is implemented using the transformers library in Python.

This model has been quantized to 4-bit precision using the GPTQ method. It has a total of approximately 1.13 billion parameters. The model is designed for text-generation tasks and includes a prompt template that provides instructions for completing requests.

## Usage example

```python
from transformers import GPT2Tokenizer, GPT2LMHeadModel

tokenizer = GPT2Tokenizer.from_pretrained("TheBloke/WizardCoder-Python-7B-V1.0-GPTQ")
model = GPT2LMHeadModel.from_pretrained("TheBloke/WizardCoder-Python-7B-V1.0-GPTQ")

# Generate Python code based on a prompt
prompt = "Write a Python function to calculate the factorial of a number."
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids, max_length=100)

generated_code = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_code)
```

Please note that this model is trained for text generation tasks and is specifically optimized for Python code.
