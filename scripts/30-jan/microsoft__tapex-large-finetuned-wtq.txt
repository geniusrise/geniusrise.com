# Model name

tapex-large-finetuned-wtq

## Links

- Hugging Face Model Page: [tapex-large-finetuned-wtq](https://huggingface.co/microsoft/tapex-large-finetuned-wtq)
- GitHub Repository: [microsoft/tapex-large-finetuned-wtq](https://github.com/microsoft/tapex-large-finetuned-wtq)

## Description

The tapex-large-finetuned-wtq model is a large-scale, fine-tuned language model based on the BART architecture and trained using the TAPEx (Table Pre-training via Learning a Neural SQL Executor) framework. It is designed for table question answering tasks and provides answers to questions related to tables.

This model is trained on the wikitablequestions dataset and has around 406 million parameters. It is compatible with the Transformers library and can be used with Python.

## Usage example

To use the tapex-large-finetuned-wtq model, you can use the Transformers library in Python. Here's an example:

```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model_name = "microsoft/tapex-large-finetuned-wtq"
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

inputs = tokenizer.encode("What is the capital of France?", return_tensors="pt")
outputs = model.generate(inputs)

decoded_outputs = [tokenizer.decode(idx) for idx in outputs]
print(decoded_outputs)
```

This example demonstrates how to load the tapex-large-finetuned-wtq model and generate answers for a given question.
