## Description

The `kobart-news` model is a BART-based model trained on Korean news articles for the task of summarization. It is implemented using the transformers library in Python. The model has been fine-tuned to generate summaries of news articles in the Korean language.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("ainize/kobart-news")
model = AutoModelForSeq2SeqLM.from_pretrained("ainize/kobart-news")

input_text = "이 모델은 한국어 뉴스 기사 요약을 생성하는 데 사용됩니다."
input_ids = tokenizer.encode(input_text, return_tensors="pt")
summary_ids = model.generate(input_ids)

summary_text = tokenizer.decode(summary_ids[0])
print(summary_text)
```

This will generate a summary of the input news article in Korean using the `kobart-news` model.
