Whisper

## Description

Whisper is a pre-trained model for automatic speech recognition (ASR) and speech translation. It was trained on 680k hours of labeled data using large-scale weak supervision. The model is a Transformer-based encoder-decoder model, also known as a sequence-to-sequence model. It demonstrates a strong ability to generalize to different datasets and domains without the need for fine-tuning. Whisper models come in five different configurations of varying model sizes, trained on either English-only data or multilingual data. The largest checkpoints are trained only on multilingual data. The model can be used for tasks like transcription (speech recognition) and translation (speech translation).

## Usage example

To transcribe audio samples using the Whisper model, you need to use it alongside a WhisperProcessor. The WhisperProcessor is used to pre-process the audio inputs (converting them to log-Mel spectrograms for the model) and post-process the model outputs (converting them from tokens to text). The model is informed about the task to perform (transcription or translation) by passing the appropriate "context tokens". These context tokens specify the language, the task, and whether to include timestamp prediction. The model can be used for different transcription and translation tasks by modifying the context tokens accordingly.

Here are some usage examples:

### Transcription

#### English to English

```python
from transformers import WhisperProcessor, WhisperForConditionalGeneration
from datasets import load_dataset

# load model and processor
processor = WhisperProcessor.from_pretrained("openai/whisper-large-v2")
model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-large-v2")
model.config.forced_decoder_ids = None

# load dummy dataset and read audio files
ds = load_dataset("hf-internal-testing/librispeech_asr_dummy", "clean", split="validation")
sample = ds[0]["audio"]
input_features = processor(sample["array"], sampling_rate=sample["sampling_rate"], return_tensors="pt").input_features

# generate token ids
predicted_ids = model.generate(input_features)
# decode token ids to text
transcription = processor.batch_decode(predicted_ids, skip_special_tokens=False)
```

#### French to French

```python
from transformers import WhisperProcessor, WhisperForConditionalGeneration
from datasets import Audio, load_dataset

# load model and processor
processor = WhisperProcessor.from_pretrained("openai/whisper-large-v2")
model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-large-v2")
forced_decoder_ids = processor.get_decoder_prompt_ids(language="french", task="transcribe")

# load streaming dataset and read first audio sample
ds = load_dataset("common_voice", "fr", split="test", streaming=True)
ds = ds.cast_column("audio", Audio(sampling_rate=16_000))
input_speech = next(iter(ds))["audio"]
input_features = processor(input_speech["array"], sampling_rate=input_speech["sampling_rate"], return_tensors="pt").input_features

# generate token ids
predicted_ids = model.generate(input_features, forced_decoder_ids=forced_decoder_ids)
# decode token ids to text
transcription = processor.batch_decode(predicted_ids, skip_special_tokens=True)
```

## Business use cases

Whisper can be used in various business use cases, such as:

1. Call center speech transcription: The model can transcribe customer calls automatically, enabling call centers to review and analyze customer interactions more efficiently.

2. Multilingual customer support: Whisper's multilingual models can be used to translate customer queries in one language to support agents who speak a different language, facilitating effective communication.

3. Voice assistants and chatbots: The model can be used to power voice assistants and chatbots, enabling natural and accurate speech recognition and translation for user interactions.

4. Speech-to-text applications: Whisper can be used as a core component in speech-to-text applications, allowing users to dictate text instead of typing it manually.

5. Language learning and translation services: Whisper's multilingual models can be utilized in language learning platforms or translation services to provide automated speech translation between different languages.

Please note that it is essential to perform robust evaluations of the model in specific contexts and domains before deploying it for any business application.
