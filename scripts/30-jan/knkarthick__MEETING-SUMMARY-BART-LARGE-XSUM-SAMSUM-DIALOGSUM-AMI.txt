## Description
The MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI model is built using the BART-LARGE architecture and is trained on XSUM, SAMSUM, DIALOGSUM, and AMI datasets. It is designed for meeting summarization tasks and uses GPTQ and AWQ methods for generating summaries. The model has a large number of parameters and offers advanced performance in meeting summarization.

## Usage example
```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model_name = "knkarthick/MEETING-SUMMARY-BART-LARGE-XSUM-SAMSUM-DIALOGSUM-AMI"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

inputs = tokenizer.encode("Meeting transcript goes here", return_tensors="pt")
outputs = model.generate(inputs, max_length=100)

summary = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(summary)
```

Note: You can replace "Meeting transcript goes here" with the actual meeting transcript you want to summarize.
