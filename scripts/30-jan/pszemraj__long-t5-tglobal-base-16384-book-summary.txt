## Description
The `pszemraj/long-t5-tglobal-base-16384-book-summary` model is a Transformer-based model designed for book summarization tasks. It addresses the limitation of transformers with its O(n^2) time and memory complexity by using block sparse attention instead of normal attention. This model can handle longer sequences, up to a length of 4096, at a much lower computational cost compared to traditional transformer models like BERT. It has achieved state-of-the-art performance on tasks involving long document summarization and question-answering with long contexts. The model is trained on datasets such as `kmfoda/booksum` and evaluates its performance using the ROUGE metric.

## Usage example
```python
from transformers import AutoTokenizer, T5ForConditionalGeneration

tokenizer = AutoTokenizer.from_pretrained("pszemraj/long-t5-tglobal-base-16384-book-summary")
model = T5ForConditionalGeneration.from_pretrained("pszemraj/long-t5-tglobal-base-16384-book-summary")

input_text = "The tower is 324 metres (1,063 ft) tall, about the same height as an 81-storey building, and the tallest structure in Paris."
input_ids = tokenizer.encode(input_text, return_tensors="pt")
outputs = model.generate(input_ids, max_length=50)

summary = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(summary)
```

This example demonstrates how to use the `pszemraj/long-t5-tglobal-base-16384-book-summary` model for book summarization. The input text is encoded using the model's tokenizer, and the `generate` method is used to generate a summary. The maximum length of the summary is set to 50 tokens. The decoded summary is then printed.
