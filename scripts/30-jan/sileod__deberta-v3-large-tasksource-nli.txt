## Description

This model is based on the DeBERTa-v3-large architecture and is fine-tuned on the Natural Language Inference (NLI) task. It is part of the DeBERTa-v3 series of models, which are optimized for extreme multitasking and can handle a wide range of tasks, including zero-shot classification. The model is trained using the Transformers library and Python.

The model's pipeline tag is "zero-shot-classification" indicating its ability to perform zero-shot classification on unseen classes.

The model supports multiple datasets, including GLUE, SuperGLUE, ANLI, SNLI, SciTail, HANS, and more. It has a total of 40600 downloads.

The model is developed by Damien Sileo (sileod) and is licensed under the Apache 2.0 license. The model is available in English.

## Usage example

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer

model_name = "sileod/deberta-v3-large-tasksource-nli"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name)

sentence = "This is an example sentence."
inputs = tokenizer.encode_plus(sentence, add_special_tokens=True, return_tensors="pt")
outputs = model(**inputs)

# Get predicted label
predicted_label = tokenizer.decode(outputs.logits.argmax(), skip_special_tokens=True)

print("Predicted label:", predicted_label)
```
