# Model name

cardiffnlp/twitter-xlm-roberta-base-sentiment

## Links

- [Model Page](https://huggingface.co/cardiffnlp/twitter-xlm-roberta-base-sentiment)
- [GitHub Repo](https://github.com/cardiffnlp/tweeteval/tree/main/models/sentiment/twitter-xlm-roberta-base)

## Description

The cardiffnlp/twitter-xlm-roberta-base-sentiment model is a transformer-based model trained on multilingual data for sentiment analysis in text classification tasks. It utilizes the XLM-RoBERTa architecture and is compatible with the transformers library in Python. The model is suited for tasks such as sentiment analysis in social media posts and other multilingual text classification tasks. It has been trained on a large amount of Twitter data and can handle various sentiment classes.

The model has been built by Cardiff NLP and is hosted on the Hugging Face Model Hub.

## Usage example

```python
from transformers import pipeline

# Load the sentiment analysis pipeline
pipeline_name = "cardiffnlp/twitter-xlm-roberta-base-sentiment"
sentiment_pipeline = pipeline("text-classification", model=pipeline_name, tokenizer=pipeline_name)

# Analyze sentiment of a text
text = "I love this movie!"
sentiment = sentiment_pipeline(text)
print(sentiment)
```

Note: Replace `pipeline_name` with the actual model name "cardiffnlp/twitter-xlm-roberta-base-sentiment" when using the code.
