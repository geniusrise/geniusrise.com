## Description

The MMS-TTS Marathi Text-to-Speech model is an end-to-end speech synthesis model developed as part of Facebook's Massively Multilingual Speech project. It is based on the VITS (Variational Inference with adversarial learning for end-to-end Text-to-Speech) architecture, which is a conditional variational autoencoder (VAE) comprised of a posterior encoder, decoder, and conditional prior. It includes a stack of transposed convolutional layers for decoding spectrograms and a stochastic duration predictor to enable synthesis of speech with different rhythms from the same input text. The model is trained with a combination of losses derived from variational lower bound and adversarial training.

The MMS-TTS Marathi model is one of the checkpoints trained on different languages for the MMS project.

The model is available in the Transformers library from version 4.33 onwards.

## Usage example

To use the MMS-TTS Marathi model, first install the latest version of the Transformers library:

```python
pip install --upgrade transformers accelerate
```

Then, run inference with the following code snippet:

```python
from transformers import VitsModel, AutoTokenizer
import torch

model = VitsModel.from_pretrained("facebook/mms-tts-mar")
tokenizer = AutoTokenizer.from_pretrained("facebook/mms-tts-mar")

text = "some example text in the Marathi language"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    output = model(**inputs).waveform
```

The resulting waveform can be saved as a .wav file or displayed in a Jupyter Notebook / Google Colab.

1. Text-to-speech applications: The model can be used to convert textual data into speech, enabling the development of voice assistants and audio-based applications.
2. Language learning: The model can be used to provide audio content for language learning platforms, allowing users to listen to Marathi pronunciations of words and sentences.
3. Audiobook production: The model can be used to automate the creation of audiobooks by converting written text into natural-sounding speech in the Marathi language.
4. Accessibility: The model can be used to generate audio representations of written content, making it accessible to individuals with visual impairments.
5. Entertainment: The model can be used in the production of voice-overs for videos, movies, and animations, enhancing the overall audio experience.
