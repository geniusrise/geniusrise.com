# Model name

cross-encoder/nli-deberta-v3-small

## Links

- [Model Page](https://huggingface.co/cross-encoder/nli-deberta-v3-small)
- [GitHub Repo](https://github.com/cross-encoder/nli-deberta-v3-small)

## Description

The `cross-encoder/nli-deberta-v3-small` model is a fine-tuned version of the `microsoft/deberta-v3-small` model for natural language inference (NLI) tasks. It is specifically designed for zero-shot classification using the Transformers library with Python. The model has been trained on the `multi_nli` and `snli` datasets. It has a pipeline tag of "zero-shot-classification" and architecture of "DebertaV2ForSequenceClassification". The model supports inference and is compatible with autotrain and inference endpoints. The license for the model is Apache 2.0.

## Usage example

```python
from transformers import pipeline

classifier = pipeline(
    "zero-shot-classification",
    model="cross-encoder/nli-deberta-v3-small",
    tokenizer="cross-encoder/nli-deberta-v3-small"
)

sequence = "I have a problem with my iPhone that needs to be resolved asap!!"
candidate_labels = ["urgent", "not urgent", "phone", "tablet", "computer"]

result = classifier(sequence, candidate_labels)

print(result)
```

This example demonstrates how to use the `cross-encoder/nli-deberta-v3-small` model for zero-shot classification. In this case, we provide a sequence (text) and a list of candidate labels. The model predicts the most suitable label(s) for the given sequence.
