# Model name
SauerkrautLM-UNA-SOLAR-Instruct-AWQ

## Links
- [Original Hugging Face Model Page](https://huggingface.co/TheBloke/SauerkrautLM-UNA-SOLAR-Instruct-AWQ)

## Description
SauerkrautLM-UNA-SOLAR-Instruct-AWQ is AWQ quantized model variants of Yağız Çalık's SauerkrautLM Una SOLAR Instruct. AWQ (Adaptive Weight Quantization) is a method for efficient quantization, currently supporting 4-bit configurations and offering faster Transformers-based inference compared to GPTQ. It has hardware requirements of Linux or Windows with NVidia GPUs, but not supported on macOS (use GGUF models instead).

Model is currently given with parameters for 4-bits and group size of 128, using the VMware Open Instruct dataset with a sequence length configuration of 4096, totaling around 5.96 GB. These AWQ models are usable in various platforms including text-generation-webui (Loader: AutoAWQ), vLLM, Hugging Face Text Generation Inference (TGI), Transformers library, and AutoAWQ for Python code.

## Usage example
### Transformers Library (Python)
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name_or_path = "TheBloke/SauerkrautLM-UNA-SOLAR-Instruct-AWQ"

tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)
model = AutoModelForCausalLM.from_pretrained(
    model_name_or_path,
    low_cpu_mem_usage=True,
    device_map="cuda:0"
)

# Generate prompt
prompt = "Tell me about AI"
generated = model.generate(
    tokenizer.encode(prompt, return_tensors='pt'),
    max_length=50,
    num_return_sequences=5
)

print(tokenizer.decode(generated[0], skip_special_tokens=True))
```
Note: Replace `cuda:0` with your GPU device or `cpu` for CPU-only inference. Modify `max_length` and `num_return_sequences` as needed.
