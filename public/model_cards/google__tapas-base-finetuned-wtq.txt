# Model name

google/tapas-base-finetuned-wtq

## Links
- [Hugging Face Model Page](https://huggingface.co/google/tapas-base-finetuned-wtq)

## Description
The `google/tapas-base-finetuned-wtq` model is a finetuned version of the TAPAS (TAble PArSing) model developed by Google. It is trained for table question answering (QA) tasks. This model is based on the TapasForQuestionAnswering architecture and is available in the transformers library. It has been finetuned on the WikitableQuestions dataset.

## Usage example
You can use this model with the transformers library in Python. For example, you can use it to perform table question answering tasks with the following code:

```python
from transformers import TapasForQuestionAnswering, TapasTokenizer

model = TapasForQuestionAnswering.from_pretrained("google/tapas-base-finetuned-wtq")
tokenizer = TapasTokenizer.from_pretrained("google/tapas-base-finetuned-wtq")

# Prepare input
table = [["Country", "Capital"], ["Germany", "Berlin"], ["France", "Paris"]]
queries = ["What is the capital of Germany?", "What is the capital of France?"]

inputs = tokenizer(table=table, queries=queries, padding="max_length", truncation=True, return_tensors="pt")

# Perform inference
outputs = model(**inputs)

# Get the predicted answer
answer = tokenizer.convert_tokens_to_string(tokenizer.convert_ids_to_tokens(outputs["answer"]))

print(answer)
```

This example demonstrates how to use the `google/tapas-base-finetuned-wtq` model to answer questions based on a given table.
