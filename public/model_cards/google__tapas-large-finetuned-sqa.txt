# Model name

google/tapas-large-finetuned-sqa

## Links

- [Original Hugging Face page](https://huggingface.co/google/tapas-large-finetuned-sqa)

## Description

The `google/tapas-large-finetuned-sqa` model is a large-scale, fine-tuned version of Tapas (Table-based Parser), trained by Google. Tapas is an NLP model that is specifically designed for table question answering. It is trained to answer natural language questions about tabular data. This model has been fine-tuned on the `msr_sqa` dataset, which includes question and answer pairs for tables.

The model uses the Transformers library with Python. It has a large number of parameters, but the exact count is not mentioned in the description. Please refer to the Hugging Face page for more details.

## Usage example

```python
from transformers import TapasForQuestionAnswering, TapasTokenizer

# Load the model
model = TapasForQuestionAnswering.from_pretrained("google/tapas-large-finetuned-sqa")
tokenizer = TapasTokenizer.from_pretrained("google/tapas-large-finetuned-sqa")

# Prepare input
table = [["Country", "Population"], ["USA", "328 million"], ["China", "1.4 billion"]]
questions = ["What is the population of the USA?", "How many people live in China?"]

encoded_inputs = tokenizer(table=table, queries=questions, padding="max_length", truncation=True, return_tensors="pt")

# Make predictions
outputs = model(**encoded_inputs)

answer_coordinates, predicted_aggregation_indices = outputs.answer_coordinates, outputs.predicted_aggregation_indices
answer = tokenizer.convert_coordinates_to_tokens(table, answer_coordinates.tolist()[0])[0]

print("Answer:", answer)
```

Please refer to the [original Hugging Face page](https://huggingface.co/google/tapas-large-finetuned-sqa) for more examples and details on using this model.
