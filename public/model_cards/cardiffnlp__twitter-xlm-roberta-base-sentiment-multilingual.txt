## Description
The `twitter-xlm-roberta-base-sentiment-multilingual` model is a multilingual sentiment analysis model based on the XLM-RoBERTa architecture. It is trained to predict the sentiment of tweets in multiple languages. The model can be used for tasks such as identifying positive, negative, or neutral sentiment in social media posts.

<!--## Usage example -->
## Usage example
You can use the `transformers` library in Python to work with the `twitter-xlm-roberta-base-sentiment-multilingual` model. The model has been trained on the `cardiffnlp/tweet_sentiment_multilingual` dataset. It has a total of 32,997 downloads and has achieved a micro F1 score of 0.693 and an accuracy of 0.693 on the test set of the dataset.

To use the model, you can follow the example below:

```
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cardiffnlp/twitter-xlm-roberta-base-sentiment-multilingual")
model = AutoModelForSequenceClassification.from_pretrained("cardiffnlp/twitter-xlm-roberta-base-sentiment-multilingual")

text = "I love swimming for the same reason I love meditating...the feeling of weightlessness."
encoded_input = tokenizer(text, padding=True, truncation=True, return_tensors="pt")
output = model(**encoded_input)

logits = output.logits
predicted_sentiment = torch.argmax(logits, dim=1).item()
sentiment_labels = {0: "Negative", 1: "Neutral", 2: "Positive"}
sentiment = sentiment_labels[predicted_sentiment]

print("Input text:", text)
print("Predicted sentiment:", sentiment)
```
