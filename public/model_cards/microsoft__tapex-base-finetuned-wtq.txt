# Model name

microsoft/tapex-base-finetuned-wtq

## Links

- [Hugging Face model page](https://huggingface.co/microsoft/tapex-base-finetuned-wtq)

## Description

The `microsoft/tapex-base-finetuned-wtq` model is a finetuned version of the TAPeX (Table Pre-training via Learning a Neural SQL Executor) model from Microsoft. It is specifically trained for table question answering tasks. It is based on the BART architecture and fine-tuned using the WikiTableQuestions dataset.

The model can be used for table question answering tasks where the input is a question related to a table and the output is the answer to the question.

This model can be accessed using the [transformers](https://huggingface.co/transformers) library in Python.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

# Load the tokenizer and model
tokenizer = AutoTokenizer.from_pretrained("microsoft/tapex-base-finetuned-wtq")
model = AutoModelForSeq2SeqLM.from_pretrained("microsoft/tapex-base-finetuned-wtq")

# Prepare input
question = "How many stars does the Hugging Face repository have?"
input_text = f"question: {question} table: <table here>"

# Tokenize input
inputs = tokenizer(input_text, truncation=True, padding="longest", return_tensors="pt")

# Generate output
outputs = model.generate(inputs.input_ids)

# Decode output
decoded_output = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(decoded_output)
```

Please note that `<table here>` in the code above should be replaced with the actual table to be used for the question answering task.

For more details and usage examples, refer to the [Hugging Face model page](https://huggingface.co/microsoft/tapex-base-finetuned-wtq).
