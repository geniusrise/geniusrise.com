## Description

The microsoft/tapex-base-finetuned-wtq model is a table question-answering model based on the BART architecture from the transformers library. It has been fine-tuned on the WikitableQuestions dataset. The model is suitable for performing table question-answering tasks and can generate answers to questions based on tables.

Key details:

- Architecture: BARTForConditionalGeneration
- Model type: BART
- Language: English
- Tags: transformers, pytorch, safetensors, bart, text2text-generation, tapex, table-question-answering
- Datasets: WikitableQuestions
- Number of parameters: Not specified

## Usage example

Here is an example of how to use the model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("microsoft/tapex-base-finetuned-wtq")
model = AutoModelForSeq2SeqLM.from_pretrained("microsoft/tapex-base-finetuned-wtq")

input_text = "What is the population of New York City?"
encoded_input = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(encoded_input)

decoded_output = tokenizer.decode(output[0])
print(decoded_output)
```

This example uses the model to answer the question "What is the population of New York City?" The input text is tokenized using the tokenizer, and the encoded input is passed to the model for generation. The generated output is then decoded using the tokenizer, and the answer is printed out.

Please note that the number of parameters for the model is not specified on the model page.
