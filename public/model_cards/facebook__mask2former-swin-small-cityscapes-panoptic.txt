## Description

Mask2Former is a model trained on Cityscapes panoptic segmentation with a small-sized version of the Swin backbone. It addresses instance, semantic, and panoptic segmentation by predicting a set of masks and corresponding labels. Mask2Former outperforms previous state-of-the-art model MaskFormer in terms of performance and efficiency by utilizing a more advanced multi-scale deformable attention Transformer in the pixel decoder, adopting a Transformer decoder with masked attention, and improving training efficiency by calculating loss on subsampled points instead of whole masks.

## Usage example

Here is an example of how to use the Mask2Former Swin Small Cityscapes Panoptic model:

```python
import requests
import torch
from PIL import Image
from transformers import AutoImageProcessor, Mask2FormerForUniversalSegmentation

# Load Mask2Former fine-tuned on Cityscapes panoptic segmentation
processor = AutoImageProcessor.from_pretrained("facebook/mask2former-swin-small-cityscapes-panoptic")
model = Mask2FormerForUniversalSegmentation.from_pretrained("facebook/mask2former-swin-small-cityscapes-panoptic")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)
inputs = processor(images=image, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

# Model predicts class_queries_logits of shape `(batch_size, num_queries)`
# and masks_queries_logits of shape `(batch_size, num_queries, height, width)`
class_queries_logits = outputs.class_queries_logits
masks_queries_logits = outputs.masks_queries_logits

# You can pass them to the processor for postprocessing
result = processor.post_process_panoptic_segmentation(outputs, target_sizes=[image.size[::-1]])[0]
# We refer to the demo notebooks for visualization (see "Resources" section in the Mask2Former docs)
predicted_panoptic_map = result["segmentation"]

For more code examples, please refer to the documentation.
```
