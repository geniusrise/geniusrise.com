## Description

The `pszemraj/led-large-book-summary` model is a transformer-based model that is designed for long-form narrative summarization. It is trained on the BookSum dataset, which consists of source documents from the literature domain, such as novels, plays, and stories. The dataset includes highly abstractive, human-written summaries at three different levels of granularity: paragraph, chapter, and book. The model addresses the challenges of processing very long documents, handling non-trivial causal and temporal dependencies, and understanding rich discourse structures.

The model utilizes block sparse attention instead of normal attention to handle sequences up to a length of 4096, reducing the computational cost compared to models like BERT. It has achieved state-of-the-art performance on tasks involving summarization of long documents, such as long documents summarization and question-answering with long contexts.

The model is available for use with the 🤗Transformers library in Python.

## Usage example

Here is an example of how to use the `pszemraj/led-large-book-summary` model with the Transformers library in Python:

```python
from transformers import pipeline

summarizer = pipeline(
    "summarization",
    model="pszemraj/led-large-book-summary",
    tokenizer="pszemraj/led-large-book-summary"
)

text = "Your input text goes here"
summary = summarizer(text)[0]['summary_text']

print(summary)
```

The example demonstrates how to create a summarization pipeline using the `pszemraj/led-large-book-summary` model and tokenizer, and then summarize an input text. The resulting summary is printed.

Please note that the model has a maximum sequence length of 4096 and requires the use of a compatible tokenizer to ensure proper tokenization.

For more information and additional examples, refer to the [model page](https://huggingface.co/pszemraj/led-large-book-summary).
