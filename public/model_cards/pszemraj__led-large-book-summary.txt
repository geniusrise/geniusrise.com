# Model name

pszemraj/led-large-book-summary

## Links

- [Huggingface Model Page](https://huggingface.co/pszemraj/led-large-book-summary)

## Description

The pszemraj/led-large-book-summary model is a transformer-based model that is designed for long-form narrative summarization tasks. It addresses the limitations of transformer models in handling long sequences by using block sparse attention instead of normal attention. This allows the model to handle sequences up to a length of 4096 with lower computational cost compared to traditional transformer models. The model has achieved state-of-the-art performance on tasks involving long sequences, such as long document summarization and question-answering with long contexts. It is trained and evaluated on the BookSum dataset, which includes long-form source documents from the literature domain.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

# Load the tokenizer and model
tokenizer = AutoTokenizer.from_pretrained("pszemraj/led-large-book-summary")
model = AutoModelForSeq2SeqLM.from_pretrained("pszemraj/led-large-book-summary")

# Example input
input_text = "A typical feed-forward neural field algorithm. Spatiotemporal coordinates are fed into a neural network that predicts values in the reconstructed domain."

# Tokenize the input
inputs = tokenizer(input_text, return_tensors="pt")

# Generate the summary
summary_ids = model.generate(inputs.input_ids, num_beams=4, max_length=64, length_penalty=0.3, early_stopping=True)
summary = tokenizer.decode(summary_ids[0])

print(summary)
```

Note: The above example demonstrates how to use the model with the Python `transformers` library.
