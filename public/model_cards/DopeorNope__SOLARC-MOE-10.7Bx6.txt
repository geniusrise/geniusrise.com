# Model name

SOLARC-MOE-10.7Bx6

## Links

- Hugging Face model page: [https://huggingface.co/DopeorNope/SOLARC-MOE-10.7Bx6](https://huggingface.co/DopeorNope/SOLARC-MOE-10.7Bx6)

## Description

SOLARC-MOE-10.7Bx6 is a text generation model trained on the SOLARC dataset. It is based on the MixtralForCausalLM architecture and is available in the transformers library. The model has a total of 53,011,288,064 parameters.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("DopeorNope/SOLARC-MOE-10.7Bx6")
model = AutoModelForCausalLM.from_pretrained("DopeorNope/SOLARC-MOE-10.7Bx6")

prompt = "Once upon a time,"
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

Please note that this model is trained on the SOLARC dataset and is suitable for text generation tasks.
