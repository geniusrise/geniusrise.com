# Model name

Mixtral_11Bx2_MoE_19B

## Links

[Original Hugging Face page](https://huggingface.co/cloudyu/Mixtral_11Bx2_MoE_19B)

## Description

Mixtral_11Bx2_MoE_19B is a text generation model based on the Mixtral architecture. It has a total of 19 billion parameters and is compatible with the Transformers library. The model is trained on a large dataset and can generate text in a wide range of domains.

## Usage example

To use the Mixtral_11Bx2_MoE_19B model with Python and the transformers library, you can follow these steps:

1. Install the transformers library: `pip install transformers`
2. Load the model:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "cloudyu/Mixtral_11Bx2_MoE_19B"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)
```

3. Generate text:

```python
input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

This will generate a continuation of the input text using the Mixtral_11Bx2_MoE_19B model.
