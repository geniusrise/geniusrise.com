# Model name

Google BigBird-Pegasus Large ARXIV

## Links

- [Hugging Face Model Page](https://huggingface.co/google/bigbird-pegasus-large-arxiv)
- [GitHub Repository](https://github.com/google-research/bigbird)

## Description

This model is part of the Google BigBird-Pegasus family and is trained for the task of summarization. It is based on the Pegasus model and uses the BigBird architecture, which allows for more efficient processing of long sequences. The model achieves state-of-the-art performance on a variety of summarization datasets, including scientific papers, CNN/DailyMail, XSum, and SamSum.

The model requires the `transformers` library in Python for usage examples. It is available under the Apache-2.0 license.

## Usage example

```python
from transformers import BigBirdPegasusForConditionalGeneration, BigBirdTokenizer

model_name = "google/bigbird-pegasus-large-arxiv"

tokenizer = BigBirdTokenizer.from_pretrained(model_name)
model = BigBirdPegasusForConditionalGeneration.from_pretrained(model_name)

input_text = "..."
inputs = tokenizer([input_text], truncation=True, padding=True, max_length=4096, return_tensors="pt")
summary_ids = model.generate(inputs.input_ids)

summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
```

Note: The above code is a simplified example. Please refer to the official documentation and example notebooks for more details on usage.
