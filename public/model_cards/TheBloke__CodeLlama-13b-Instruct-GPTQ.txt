# Model name

CodeLlama-13B-Instruct-GPTQ

## Links

- [Hugging Face Model Page](https://huggingface.co/TheBloke/CodeLlama-13B-Instruct-GPTQ)

## Description

CodeLlama-13B-Instruct-GPTQ is a language model trained on the CodeLlama dataset specifically for text generation tasks. It is based on the GPTQ model architecture.

The model has been fine-tuned using the transformers library in Python. It has a total of 13 billion parameters and is capable of generating code to solve coding problems, while obeying specific constraints and passing example test cases.

This model is part of the CodeLlama project, which aims to provide open foundation models for code generation. It is suitable for tasks related to text generation and is compatible with the transformers library. The model is licensed under the Llama 2 license.

## Usage example

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "TheBloke/CodeLlama-13B-Instruct-GPTQ"
model = GPT2LMHeadModel.from_pretrained(model_name)
tokenizer = GPT2Tokenizer.from_pretrained(model_name)

# Encode input text
input_text = "[INST] Write code to solve the following coding problem that obeys the constraints and passes the example test cases."
input_ids = tokenizer.encode(input_text, return_tensors="pt")

# Generate code
output = model.generate(input_ids, max_length=200, num_return_sequences=1, no_repeat_ngram_size=2)
generated_code = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_code)
```

For more details and examples, please refer to the [Hugging Face Model Page](https://huggingface.co/TheBloke/CodeLlama-13B-Instruct-GPTQ).
