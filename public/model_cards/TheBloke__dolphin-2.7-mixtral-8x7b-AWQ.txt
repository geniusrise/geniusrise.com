## Description

The dolphin-2.7-mixtral-8x7b-AWQ model is a mixtral-based text generation model. It was created by TheBloke. The model is designed for text generation tasks and is trained on multiple datasets, including "ehartford/dolphin", "jondurbin/airoboros-2.2.1", "ehartford/dolphin-coder", "teknium/openhermes", "ise-uiuc/Magicoder-OSS-Instruct-75K", "ise-uiuc/Magicoder-Evol-Instruct-110K", and "LDJnr/Capybara". The model is available in English.

The model configuration includes the architecture "MixtralForCausalLM" and the model type "mixtral". The model uses 4-bit quantization with AWQ (Adaptive Weight Quantization). The total number of parameters for the model is not mentioned in the provided information.

## Usage example

Here is an example of how to use the dolphin-2.7-mixtral-8x7b-AWQ model with the Transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/dolphin-2.7-mixtral-8x7b-AWQ"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids, max_length=50, num_return_sequences=5)

for i, generated_sequence in enumerate(output):
    sequence = tokenizer.decode(generated_sequence, skip_special_tokens=True)
    print(f"Generated sequence {i+1}: {sequence}")
```
