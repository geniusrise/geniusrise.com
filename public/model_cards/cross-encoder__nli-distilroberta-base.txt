# Model name

nli-distilroberta-base

## Links

- [Hugging Face Model Page](https://huggingface.co/cross-encoder/nli-distilroberta-base)
- [GitHub Repo](https://github.com/cross-encoder/nli-distilroberta-base)

## Description

The nli-distilroberta-base model is a cross-encoder model based on distilroberta-base. It is trained for natural language inference (NLI) tasks and can perform zero-shot classification. The model is fine-tuned on the multi_nli and snli datasets. It has a total of 66 million parameters.

## Usage example

To use the nli-distilroberta-base model with the transformers library in Python, you can follow this code snippet:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cross-encoder/nli-distilroberta-base")
model = AutoModelForSequenceClassification.from_pretrained("cross-encoder/nli-distilroberta-base")

inputs = tokenizer("sentence 1", "sentence 2", return_tensors="pt", padding=True, truncation=True)
outputs = model(**inputs)

logits = outputs.logits
```

Please refer to the official documentation for more details on how to use the model with the transformers library.
