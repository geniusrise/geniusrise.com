## Description

The alvaroalon2/biobert_chemical_ner model is a token classification model trained using the BioBERT architecture. It is specifically designed for named entity recognition (NER) tasks related to chemical entities in biomedical text. The model is based on the BERT architecture and is trained on diverse biomedical datasets such as BC5CDR-chemicals and BC4CHEMD. It belongs to the token-classification pipeline and is compatible with the transformers library in Python.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification

tokenizer = AutoTokenizer.from_pretrained("alvaroalon2/biobert_chemical_ner")
model = AutoModelForTokenClassification.from_pretrained("alvaroalon2/biobert_chemical_ner")

text = "Some example text"
inputs = tokenizer.encode_plus(text, return_tensors="pt")
outputs = model(**inputs)
```
