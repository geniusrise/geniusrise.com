## Description

CodeLlama-34B-Instruct-GPTQ is a text generation model based on the GPTQ architecture. It is trained to generate code solutions to coding problems based on given constraints and example test cases. The model's prompt template allows users to frame their coding problems, and the model generates code solutions accordingly.

The model is based on the Llama architecture and is compatible with the transformers library in Python. It has a total of 4,186,634,143 parameters. The model is primarily designed for builders and developers who need assistance in generating code solutions.

## Usage example

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "TheBloke/CodeLlama-34B-Instruct-GPTQ"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)

prompt = "[INST] Write code to solve the following coding problem that obeys the constraints and passes the example test cases. Please wrap your code answer using ```:\n"
input_text = prompt + "problem description" + "\n```[/INST]\n"

input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```

Note: This model requires the transformers library in Python.
