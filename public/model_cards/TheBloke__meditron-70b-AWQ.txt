# Model name

The model name is meditron-70B-AWQ.

## Links

You can find the model on the Hugging Face model hub at [https://huggingface.co/TheBloke/meditron-70B-AWQ](https://huggingface.co/TheBloke/meditron-70B-AWQ).

## Description

Meditron-70B-AWQ is a medical language model developed by the EPFL LLM Team. It is based on the `epfl-llm/meditron-70b` base model and is fine-tuned for various medical tasks. The model is trained on multiple datasets, including `bigbio/med_qa`, `medmcqa`, `bigbio/pubmed_qa`, and `epfl-llm/guidelines`. It is primarily used for text generation tasks, and it supports the English language.

The model has been quantized using the AWQ (Approximated Weight Quantization) method, resulting in reduced memory requirements. The model has 10,782,055 parameters.

## Usage example

You can use the `transformers` library in Python to load and use the model. Here is an example of how to generate text using the meditron-70B-AWQ model:

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "TheBloke/meditron-70B-AWQ"
model = GPT2LMHeadModel.from_pretrained(model_name)
tokenizer = GPT2Tokenizer.from_pretrained(model_name)

# Generate a text sample
prompt = "My name is John and"
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids, max_length=100, num_return_sequences=1)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_text)
```

For more details and examples, please refer to the [original Hugging Face page](https://huggingface.co/TheBloke/meditron-70B-AWQ).
