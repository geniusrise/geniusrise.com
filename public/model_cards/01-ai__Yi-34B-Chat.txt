Yi-34B-Chat

## Description

Yi-34B-Chat is a text generation model that can be used for various applications such as chatbots. It is based on the LlamaForCausalLM architecture and is part of the transformers library developed by Hugging Face. The model has a total of 34 billion parameters.

The model specializes in text generation tasks and is particularly well-suited for chat-based applications. It can generate responses based on given inputs and has been trained on various datasets.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "01-ai/Yi-34B-Chat"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "hi"

input_ids = tokenizer.encode(input_text, return_tensors="pt")
with torch.no_grad():
    output_ids = model.generate(input_ids)
    
output_text = tokenizer.decode(output_ids[:, input_ids.shape[-1]:][0], skip_special_tokens=True)
print(output_text)
```
