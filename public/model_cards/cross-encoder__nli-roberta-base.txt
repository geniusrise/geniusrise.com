# Model name
cross-encoder/nli-roberta-base

## Links
- [Hugging Face Model Card](https://huggingface.co/cross-encoder/nli-roberta-base)

## Description
The `cross-encoder/nli-roberta-base` model is a neural network model trained on the Natural Language Inference (NLI) task using the RoBERTa architecture. It is designed for zero-shot classification and can be used to determine the semantic similarity between two sentences. The model has been fine-tuned on the `multi_nli` and `snli` datasets and achieves high accuracy in NLI tasks. 

The model is based on the RoBERTa architecture and has approximately [125 million parameters](https://huggingface.co/cross-encoder/nli-roberta-base). It supports inference out of the box using the transformers library in Python.

## Usage example
```python
from transformers import pipeline

classifier = pipeline(
    "zero-shot-classification",
    model="cross-encoder/nli-roberta-base",
    tokenizer="cross-encoder/nli-roberta-base"
)

result = classifier(
    "How is the weather today?",
    ["positive", "negative"]
)
print(result)
```
