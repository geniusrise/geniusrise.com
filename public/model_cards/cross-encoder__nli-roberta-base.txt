## Description

The nli-roberta-base model is a transformer-based model that belongs to the cross-encoder repository. It is designed for natural language inference tasks and is based on the Roberta model architecture. The model has been fine-tuned on multiple datasets, including multi_nli and snli. It supports zero-shot classification using the "zero-shot-classification" pipeline tag. The model is available for use with the transformers library in Python.

## Usage example

```python
from transformers import pipeline

nli_model = pipeline("zero-shot-classification", model="cross-encoder/nli-roberta-base")
result = nli_model("I have a problem with my iPhone.", candidate_labels=["urgent", "not urgent", "phone", "tablet", "computer"])
print(result)
```

This example demonstrates how to use the nli-roberta-base model for zero-shot classification. The model is used to classify a text as belonging to one of the candidate labels provided: "urgent", "not urgent", "phone", "tablet", or "computer". The result is a dictionary containing the predicted label and its associated score.

The nli-roberta-base model has a total of 270 million parameters. It is trained to perform natural language inference tasks and has achieved an accuracy metric.
