# Model name

twitter-roberta-base-hate-latest

## Links

- [Original Hugging Face page](https://huggingface.co/cardiffnlp/twitter-roberta-base-hate-latest)

## Description

The twitter-roberta-base-hate-latest model is a text classification model trained on Twitter data to detect hate speech. It is based on the RoBERTa architecture and is available through the Hugging Face Transformers library. The model has been fine-tuned on a hate speech dataset and can be used to classify text as hate speech or non-hate speech.

The model has been trained using the transformers library in Python and has a total of 82M parameters.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cardiffnlp/twitter-roberta-base-hate-latest")
model = AutoModelForSequenceClassification.from_pretrained("cardiffnlp/twitter-roberta-base-hate-latest")

text = "I can't believe how much I hate you!"

input_ids = tokenizer.encode(text, truncation=True, padding=True, return_tensors="pt")
outputs = model(input_ids)

predictions = outputs.logits.argmax(dim=1)
```
In the example above, the model is used to classify the given text as hate speech or not. The input text is encoded using the tokenizer, and the model returns the predicted label for the text.
