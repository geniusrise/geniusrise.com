## Description

wmt21-dense-24-wide-en-x is a translation model developed by Facebook. It is part of the Transformers library and is trained on a multilingual dataset. The model has a total of 285 downloads and has been liked by 30 users. It supports various languages, including Hausa, Icelandic, Japanese, Czech, Russian, Chinese, German, and English. The model is based on the M2M100 architecture and falls under the translation pipeline tag.

## Usage example

Here is an example of how to use the wmt21-dense-24-wide-en-x model with the Transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

model_name = "facebook/wmt21-dense-24-wide-en-x"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

text = "Translate this sentence."
inputs = tokenizer.encode(text, return_tensors="pt")
outputs = model.generate(inputs)

translated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(translated_text)
```

Make sure to install the `transformers` library before running this code. The output will be the translated text generated by the model.
