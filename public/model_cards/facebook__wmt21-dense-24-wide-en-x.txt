## Description

The wmt21-dense-24-wide-en-x model is a translation model trained by Facebook. It is part of the Facebook AI WMT21 News Translation Task submission. The model is based on the m2m_100 architecture and is designed for text-to-text generation tasks, particularly translation. It is trained on various languages, including multilingual, Hausa, Icelandic, Japanese, Czech, Russian, Chinese, German, and English.

The model is available for inference and can be used with the Transformers library in Python. It has a total of 664 downloads and is liked by 30 users.

## Usage example

Here is an example of how to use the wmt21-dense-24-wide-en-x model with the Transformers library in Python:

```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model_name = "facebook/wmt21-dense-24-wide-en-x"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

text = "Translate this sentence to German."
input_ids = tokenizer(text, return_tensors="pt").input_ids
output = model.generate(input_ids)

translated_text = tokenizer.decode(output[0])
print(translated_text)
```

This will generate the translated text for the input sentence using the wmt21-dense-24-wide-en-x model.
