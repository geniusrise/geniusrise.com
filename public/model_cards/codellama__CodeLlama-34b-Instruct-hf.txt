# Model name

CodeLlama-34b-Instruct-hf

## Links

- [Hugging Face Model Card](https://huggingface.co/codellama/CodeLlama-34b-Instruct-hf)

## Description

The CodeLlama-34b-Instruct-hf model is a text generation model trained by Code Llama. It is based on the LlamaForCausalLM architecture and is part of the transformers library. The model is designed for instructing or guiding text generation tasks. It has been trained on a large amount of data and has a total of 33,743,970,304 parameters. The model supports text generation in Python using the transformers library.

## Usage example

Here is an example of how to use the CodeLlama-34b-Instruct-hf model for text generation in Python using the transformers library:

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "codellama/CodeLlama-34b-Instruct-hf"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)

prompt = "Once upon a time"
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output_ids = model.generate(input_ids, max_length=100)

generated_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)
print(generated_text)
```
