## Description

The meditron-70b model is a medical language model that is based on the Llama-2-70b base model. It is designed for text generation tasks in the medical domain. The model has been trained on several datasets, including bigbio/med_qa, medmcqa, bigbio/pubmed_qa, and epfl-llm/guidelines. It is built using the transformers library in Python.

The model has a total of 68,976,926,720 parameters. It is capable of performing text generation tasks and has been fine-tuned specifically for medical language tasks. The model is compatible with Autotrain and Inference Endpoints.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "epfl-llm/meditron-70b"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "In a recent study, researchers found that"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output_ids = model.generate(input_ids)

output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)
print(output_text)
```

This will generate a text continuation of the input prompt using the meditron-70b model. The generated text will be a medical-specific response based on the provided input.

Note: The above code is just an example. The actual implementation may vary depending on the specific use case and requirements.
