## Description

WizardMath-13B-V1.0-GPTQ is a large language model based on the GPTQ (Generative Pre-trained Transformer for Question Answering) architecture. It is part of the WizardLM project and is designed for mathematical reasoning tasks. The model uses the transformers library in Python for its usage examples.

The model has a total of 13 billion parameters and was trained using the AWQ (Artificial Wizard Questioning) technique. It supports text generation tasks and is quantized using GPTQ, achieving a 4-bit precision.

## Usage example

Here is an example of how to use the WizardMath-13B-V1.0-GPTQ model with the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/WizardMath-13B-V1.0-GPTQ"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "What is the square root of 16?"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)

generated_text = tokenizer.decode(output[0])
print(generated_text)
```

This example demonstrates how to use the model for generating responses to mathematical questions. The input text is encoded using the model's tokenizer, passed to the model for text generation, and then decoded to obtain the generated text.
