# Model name

microsoft/tapex-large-finetuned-wtq

## Links

- Hugging Face Model Card: [microsoft/tapex-large-finetuned-wtq](https://huggingface.co/microsoft/tapex-large-finetuned-wtq)

## Description

The microsoft/tapex-large-finetuned-wtq model is a large-scale language model trained using Tapex and fine-tuned on the WikitableQuestions dataset. It is based on the BART architecture and is specifically designed for table question answering tasks. The model has been trained with the help of the transformers library in Python and has achieved significant performance improvements in table question answering.

The model has a total of 406,341,721 parameters and supports inference. It has been released under the MIT license.

## Usage example

To use the microsoft/tapex-large-finetuned-wtq model with the transformers library in Python, you can simply load the model using its identifier:

```
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model = AutoModelForSeq2SeqLM.from_pretrained("microsoft/tapex-large-finetuned-wtq")
tokenizer = AutoTokenizer.from_pretrained("microsoft/tapex-large-finetuned-wtq")
```

For more details and examples, please refer to the [microsoft/tapex-large-finetuned-wtq](https://huggingface.co/microsoft/tapex-large-finetuned-wtq) page on Hugging Face.
