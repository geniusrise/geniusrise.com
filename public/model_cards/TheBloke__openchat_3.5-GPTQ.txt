## Description
The openchat_3.5-GPTQ model is a text generation model that utilizes the Transformers library with Python. It is part of the OpenChat project and is based on the OpenChat 3.5 7B model. The model's architecture is MistralForCausalLM and it is quantized using GPTQ. The model has a prompt template of "GPT4 User: {prompt}<|end_of_turn|>GPT4 Assistant:\n". The model supports text generation and is compatible with AutoTrain. The parameters for the Safetensors library used in the model are I32: 880,476,160 and F16: 318,328,832.

## Usage example
```python
from transformers import pipeline

generator = pipeline("text-generation", model="TheBloke/openchat_3.5-GPTQ")
prompt = "My name is John and I like to"
response = generator(prompt, max_length=100)

print(response[0]['generated_text'])
```
