## Description
The Sigma/financial-sentiment-analysis model is a text classification model trained with the Transformers library in Python. It is designed to perform sentiment analysis on financial text data. The model has been fine-tuned on the financial_phrasebank dataset, and it uses the BERT architecture for sequence classification. The model has been evaluated on the financial_phrasebank dataset, achieving an accuracy of 99.24% and an F1 score of 99.24%. The model has 112,397 downloads and it is compatible with the Transformers library. 

## Usage example
```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("Sigma/financial-sentiment-analysis")
model = AutoModelForSequenceClassification.from_pretrained("Sigma/financial-sentiment-analysis")
```
