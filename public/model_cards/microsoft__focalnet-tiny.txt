# Model name

FocalNet (tiny-sized model)

## Links

- [Model Page](https://huggingface.co/microsoft/focalnet-tiny)
- [GitHub Repo](https://github.com/microsoft/focalnet)

## Description

FocalNet (tiny-sized model) is a vision model trained on ImageNet-1k at a resolution of 224x224. It is based on the Focal Modulation Networks introduced in the paper "Focal Modulation Networks" by Yang et al. Focal Modulation Networks are an alternative to Vision Transformers, where self-attention is replaced by a focal modulation mechanism for modeling token interactions in vision. The focal modulation mechanism consists of hierarchical contextualization, gated aggregation, and element-wise modulation. FocalNet has shown superior performance compared to state-of-the-art self-attention models in image classification, object detection, and segmentation tasks.

The model has been released as a tiny-sized model and doesn't have an official model card, so the information provided here is from the Hugging Face team.

## Usage example

You can use FocalNet (tiny-sized model) for image classification tasks. Here is an example of how to classify an image from the COCO 2017 dataset into one of the 1,000 ImageNet classes using the model:

```python
from transformers import FocalNetImageProcessor, FocalNetForImageClassification
import torch
from datasets import load_dataset

dataset = load_dataset("huggingface/cats-image")
image = dataset["test"]["image"][0]

preprocessor = FocalNetImageProcessor.from_pretrained("microsoft/focalnet-tiny")
model = FocalNetForImageClassification.from_pretrained("microsoft/focalnet-tiny")

inputs = preprocessor(image, return_tensors="pt")

with torch.no_grad():
    logits = model(**inputs).logits

# model predicts one of the 1000 ImageNet classes
predicted_label = logits.argmax(-1).item()
print(model.config.id2label[predicted_label])
```
