# Model name

Llama-2-7b-chat-hf

## Links

- [GitHub Repo](https://github.com/meta-llama/Llama-2)

## Description

Llama-2-7b-chat-hf is a text generation model developed by Meta Llama 2. It is designed for chat-based conversational tasks and is based on the LlamaForCausalLM architecture.

The model is trained using the transformers library with Python. It has been fine-tuned on various datasets and has around 9.6 million downloads.

You can access Llama-2-7b-chat-hf by visiting the Hugging Face model page and following the instructions to enable access.

## Usage example

Here's an example of how to use Llama-2-7b-chat-hf with the transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "meta-llama/Llama-2-7b-chat-hf"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Hello, how are you?"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output_ids = model.generate(input_ids)
output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)

print(output_text)
```

Please note that you need to have the transformers library installed in order to use this model.
