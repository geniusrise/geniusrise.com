## Description

The cardiffnlp/twitter-roberta-base-offensive model is a language model trained by Cardiff NLP using the RoBERTa architecture. It is specifically designed for offensive language detection in tweets. The model is trained on a large dataset and can be used to classify whether a given tweet contains offensive language or not.

This model is implemented using the Transformers library in Python and is available for fine-tuning and inference.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cardiffnlp/twitter-roberta-base-offensive")
model = AutoModelForSequenceClassification.from_pretrained("cardiffnlp/twitter-roberta-base-offensive")

tweet = "This is a tweet containing offensive language."
inputs = tokenizer(tweet, truncation=True, padding=True, return_tensors="pt")
outputs = model(**inputs)
predictions = torch.argmax(outputs.logits)
label = tokenizer.decode(predictions)

print(f"Predicted label: {label}")
```

Note: Make sure to install the `transformers` library to use this model.
