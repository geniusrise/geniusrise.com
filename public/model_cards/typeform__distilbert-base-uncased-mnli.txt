## Description

The `distilbert-base-uncased-mnli` model is a variant of DistilBERT, which is a smaller and faster version of BERT, pretrained on the MultiNLI dataset. It is a transformer model that can be used for zero-shot classification tasks. The model has been fine-tuned on the MultiNLI dataset, which consists of natural language inference examples. It performs inference, and the model's last modified date is March 22, 2023.

The model belongs to the organization "Typeform" and has been authored by "Typeform". It has been liked by 33 users and has a total of 46,287 downloads. The model supports the following tags: transformers, pytorch, tf, safetensors, distilbert, text-classification, zero-shot-classification, en, and dataset: multi_nli.

## Usage example

The following is an example of how to use the `distilbert-base-uncased-mnli` model with the transformers library in Python:

```python
from transformers import DistilBertForSequenceClassification, DistilBertTokenizer

model_name = "typeform/distilbert-base-uncased-mnli"
tokenizer = DistilBertTokenizer.from_pretrained(model_name)
model = DistilBertForSequenceClassification.from_pretrained(model_name)

sentence = "This is a sample sentence."
encoded_input = tokenizer(sentence, return_tensors="pt")
output = model(**encoded_input)

logits = output.logits
predicted_labels = logits.argmax(dim=1)

print("Predicted label:", predicted_labels.item())
```
