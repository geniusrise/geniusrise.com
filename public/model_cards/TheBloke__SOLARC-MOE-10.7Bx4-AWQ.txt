# Model name

SOLARC-MOE-10.7Bx4-AWQ

## Links

- [Hugging Face Model Page](https://huggingface.co/TheBloke/SOLARC-MOE-10.7Bx4-AWQ)

## Description

The SOLARC-MOE-10.7Bx4-AWQ model is a text generation model based on the Mixtral architecture. It is trained on the SOLARC-MOE-10.7Bx4 dataset and has approximately 4 billion parameters. The model is fine-tuned for text generation tasks and is implemented using the transformers library in Python. It is available under the CC BY-NC-SA 4.0 license.

## Usage example

```python
# Install transformers library
!pip install transformers

from transformers import TFGPT2LMHeadModel, GPT2Tokenizer

# Load the model and tokenizer
model = TFGPT2LMHeadModel.from_pretrained("TheBloke/SOLARC-MOE-10.7Bx4-AWQ")
tokenizer = GPT2Tokenizer.from_pretrained("TheBloke/SOLARC-MOE-10.7Bx4-AWQ")

# Generate text
prompt = "Once upon a time"
input_ids = tokenizer.encode(prompt, return_tensors="tf")
outputs = model.generate(input_ids, max_length=100)

decoded_outputs = [tokenizer.decode(output, skip_special_tokens=True) for output in outputs]

print(decoded_outputs)
```
