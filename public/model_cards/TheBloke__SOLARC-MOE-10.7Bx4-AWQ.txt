## Description

The SOLARC-MOE-10.7Bx4-AWQ is a mixtral model used for text generation. It is based on the DopeorNope/SOLARC-MOE-10.7Bx4 base model. The model is compatible with the `transformers` library and supports text generation tasks. It has been trained on Korean language data and is licensed under CC-BY-NC-SA-4.0. The model has a total of 5,057,810,432 parameters.

The SOLARC-MOE-10.7Bx4-AWQ model uses the AWQ (Accelerated Weight Quantization) quantization method with 4-bit precision and the GEMM version of quantization. It also uses the SafeTensors library. 

## Usage example

Here's an example of how to use the SOLARC-MOE-10.7Bx4-AWQ model with the `transformers` library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/SOLARC-MOE-10.7Bx4-AWQ"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

prompt = "Once upon a time"

input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids, max_length=100)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

This will generate text using the SOLARC-MOE-10.7Bx4-AWQ model given a prompt.
