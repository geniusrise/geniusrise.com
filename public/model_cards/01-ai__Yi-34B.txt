# Model name

Yi-34B

## Links

- [Model page](https://huggingface.co/01-ai/Yi-34B)
- [GitHub repository](https://github.com/01-ai/Yi-34B)

## Description

Yi-34B is a text generation model trained on the LlamaForCausalLM architecture using the Transformers library in Python. It is capable of generating text based on given input.

The model has been fine-tuned on various datasets and has a total of 34,388,917,248 parameters. It is well-suited for tasks that require text generation, such as chatbots or creative writing.

The model is built with an open-source approach, aiming to advance and democratize artificial intelligence through open source and open science.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("01-ai/Yi-34B")
tokenizer = AutoTokenizer.from_pretrained("01-ai/Yi-34B")

input_text = "There's a place where time stands still. A place of breath taking wonder, but also"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=100)
decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)

print(decoded_output)
```

This will generate text based on the given input text using the Yi-34B model.
