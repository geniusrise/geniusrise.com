## Description

The cardiffnlp/tweet-topic-21-multi model is a text classification model trained on the tweet_topic_multi dataset. It is based on the RobertaForSequenceClassification architecture and is part of the Transformers library. The model is designed specifically for multi-topic classification of tweets. It has been trained to identify the topics of different tweets.

## Usage Example

To use the cardiffnlp/tweet-topic-21-multi model, you can use the Transformers library in Python. Here is a simple example:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cardiffnlp/tweet-topic-21-multi")
model = AutoModelForSequenceClassification.from_pretrained("cardiffnlp/tweet-topic-21-multi")

text = "It is great to see athletes promoting awareness for climate change."
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)
predictions = outputs.logits.argmax(dim=1)

print(predictions)
```

Please note that the model requires the Transformers library and Python to be installed in your environment.
