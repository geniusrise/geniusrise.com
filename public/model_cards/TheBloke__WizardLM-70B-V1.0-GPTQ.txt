# Model name

WizardLM-70B-V1.0-GPTQ

## Links

[Original Hugging Face Page](https://huggingface.co/TheBloke/WizardLM-70B-V1.0-GPTQ)

## Description

The WizardLM-70B-V1.0-GPTQ model is a large language model trained on the Wizard dataset. It is based on the GPT architecture and is part of the WizardLM library. The model is designed to generate helpful and detailed responses to user queries in a conversational style. It can be used for various natural language processing tasks, including text generation and language understanding.

The model has a total of 9,102,503,936 parameters and is quantized using GPTQ. It is compatible with the transformers library in Python.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/WizardLM-70B-V1.0-GPTQ"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

input_text = "Can you help me with some coding problems?"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids)

response = tokenizer.decode(output[0])
print(response)
```

This example demonstrates how to use the WizardLM-70B-V1.0-GPTQ model for text generation. The model is loaded using the `AutoModelForCausalLM` and `AutoTokenizer` classes from the `transformers` library. An input text is encoded using the tokenizer, and then passed to the model for generation. The generated response is decoded using the tokenizer and printed.
