## Description

toxigen_roberta is a text classification model based on the RoBERTa architecture. It is trained to detect adversarial and implicit hate speech. The model is implemented using the transformers library with Python. It has been trained on a large-scale machine-generated dataset.

The model has a total of 5,079,040 parameters. It is compatible with the AutoTokenizer and AutoModelForSequenceClassification classes provided by the transformers library.

## Usage example

Here is an example of how to use the toxigen_roberta model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("tomh/toxigen_roberta")
model = AutoModelForSequenceClassification.from_pretrained("tomh/toxigen_roberta")

text = "I like you. I love you."
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)

predictions = outputs.logits.softmax(dim=1)
```
