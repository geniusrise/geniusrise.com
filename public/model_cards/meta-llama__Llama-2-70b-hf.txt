# Model name

Llama-2-70b-hf

## Links

- Hugging Face Model Page: [meta-llama/Llama-2-70b-hf](https://huggingface.co/meta-llama/Llama-2-70b-hf)

## Description

Llama-2-70b-hf is a text generation model developed by Meta Llama 2. It is a variant of the Llama model for text generation tasks. The model is built using the transformers library in Python.

This model has been trained on a large amount of data and has a total of 68,976,653,312 parameters. It belongs to the GPTQ (Generalized Pre-trained Transformer for Question-answering) or AWQ (Advanced Question-answering with Transformers) family of models.

## Usage example

Here is an example of how to use the Llama-2-70b-hf model with the transformers library in Python:

```python
from transformers import LlamaForCausalLM, AutoTokenizer

model_name = "meta-llama/Llama-2-70b-hf"
model = LlamaForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

text_input = "Once upon a time,"
input_ids = tokenizer.encode(text_input, return_tensors="pt")

output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0])
print(generated_text)
```
