# Model name

google/bigbird-pegasus-large-pubmed

## Links

- Hugging Face page: [google/bigbird-pegasus-large-pubmed](https://huggingface.co/google/bigbird-pegasus-large-pubmed)

## Description

The google/bigbird-pegasus-large-pubmed model is a language model based on the BigBird-Pegasus architecture, trained by Google. It is specifically designed for the task of summarization. The model has been fine-tuned on the scientific_papers dataset, with a particular focus on the pubmed and arxiv subsets. 

The model achieves high performance on various evaluation metrics such as ROUGE-1, ROUGE-2, ROUGE-L, ROUGE-LSUM, METEOR, and loss, when evaluated on the scientific_papers dataset. It is a large-sized model with a total of 1.04 billion parameters. The model is available for use with the transformers library in Python.

## Usage example

Here is an example of how to use the google/bigbird-pegasus-large-pubmed model with the transformers library in Python:

```python
from transformers import BigBirdPegasusForConditionalGeneration, BigBirdTokenizer

model_name = "google/bigbird-pegasus-large-pubmed"
tokenizer = BigBirdTokenizer.from_pretrained(model_name)
model = BigBirdPegasusForConditionalGeneration.from_pretrained(model_name)

input_text = "The tower is 324 metres (1,063 ft) tall, about the same height as an 81-storey building, and the tallest structure in Paris. Its base is square, measuring 125 metres (410 ft) on each side."

inputs = tokenizer(input_text, truncation=True, padding=True, return_tensors="pt")
input_ids = inputs.input_ids

output = model.generate(input_ids)
summary = tokenizer.decode(output[0], skip_special_tokens=True)

print(summary)
```

For more details and options, please refer to the [Hugging Face page](https://huggingface.co/google/bigbird-pegasus-large-pubmed).
