# Model name

Google BigBird Pegasus Large PubMed

- [Hugging Face Model Page](https://huggingface.co/google/bigbird-pegasus-large-pubmed)
- [GitHub Repo](https://github.com/google/bigbird)

## Description

The Google BigBird Pegasus Large PubMed model is a text-to-text generation model for summarization tasks. It is based on the BigBird transformer architecture and has been fine-tuned on the PubMed dataset. The model is trained to generate concise summaries of scientific papers.

The model has achieved impressive results on the scientific papers dataset, with metrics such as ROUGE-1, ROUGE-2, ROUGE-L, ROUGE-LSUM, loss, meteor, and gen_len. It is suitable for developers and builders looking to leverage state-of-the-art summarization capabilities in their applications.

The model is available in the transformers library for Python and can be easily used for text generation tasks.

## Usage example

Here is an example of how to use the Google BigBird Pegasus Large PubMed model with the transformers library in Python:

```python
from transformers import BigBirdPegasusForConditionalGeneration, BigBirdPegasusTokenizer

model_name = "google/bigbird-pegasus-large-pubmed"
model = BigBirdPegasusForConditionalGeneration.from_pretrained(model_name)
tokenizer = BigBirdPegasusTokenizer.from_pretrained(model_name)

text = "This is an example text to summarize."
input_ids = tokenizer.encode(text, return_tensors="pt")
output = model.generate(input_ids)

summary = tokenizer.decode(output[0])
print("Summary:", summary)
```

Make sure to install the transformers library (`pip install transformers`) and use the appropriate model and tokenizer for your specific task.
