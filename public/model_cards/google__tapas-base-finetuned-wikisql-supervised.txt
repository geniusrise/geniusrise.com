## Description

tapas-base-finetuned-wikisql-supervised is a model for table question answering that has been fine-tuned on the Wikisql dataset. It is based on the TapasForQuestionAnswering architecture. The model is available for use in the transformers library with Python.

Some key details about the model:

- Language: English
- Tags: transformers, pytorch, tf, tapas, table-question-answering, en, dataset:wikisql, arxiv:2004.02349, arxiv:2010.00571, arxiv:1709.00103, license:apache-2.0, endpoints_compatible, has_space, region:us
- License: Apache-2.0

The model has been trained on the Wikisql dataset and has 404 downloads with 5 likes as of the last update on November 29, 2021.
