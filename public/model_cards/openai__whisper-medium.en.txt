# Model name

Whisper ASR and Speech Translation Model

## Links

- [Hugging Face Model Page](https://huggingface.co/openai/whisper-medium.en)
- [GitHub Repository](https://github.com/openai/whisper)

## Description

Whisper is a pre-trained model for automatic speech recognition (ASR) and speech translation. It is a Transformer-based encoder-decoder model trained on 680k hours of speech data. Whisper models demonstrate strong generalization capabilities and do not require fine-tuning to perform well on various datasets and domains. The model was proposed in the paper "Robust Speech Recognition via Large-Scale Weak Supervision" by Alec Radford et al. from OpenAI.

The model comes in five sizes: tiny, base, small, medium, and large. The largest checkpoints are multilingual models while the others are trained on English-only or multilingual data. The model sizes range from 39M parameters to 1550M parameters.

## Usage example

To transcribe audio samples using the Whisper model, you can use the transformers library in Python. Here is an example:

```python
from transformers import WhisperProcessor, WhisperForConditionalGeneration
from datasets import load_dataset

# Load model and processor
processor = WhisperProcessor.from_pretrained("openai/whisper-medium.en")
model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-medium.en")

# Load dummy dataset and read audio files
ds = load_dataset("hf-internal-testing/librispeech_asr_dummy", "clean", split="validation")
sample = ds[0]["audio"]
input_features = processor(sample["array"], sampling_rate=sample["sampling_rate"], return_tensors="pt").input_features

# Generate token ids
predicted_ids = model.generate(input_features)

# Decode token ids to text
transcription = processor.batch_decode(predicted_ids, skip_special_tokens=False)
```

## Business Use Cases

1. Transcription Services: The Whisper model can be used by transcription service providers to convert audio files into text. This can be valuable for generating transcripts for interviews, lectures, meetings, and other spoken content.
2. Language Learning Platforms: Language learning platforms can utilize the Whisper model to provide speech recognition and translation capabilities. This can enhance the learning experience by allowing students to practice speaking and receive real-time feedback.
3. Voice Assistants and Chatbots: The model can be integrated into voice assistants and chatbots to enable them to understand and respond to spoken user inputs. This can improve the user experience and make interactions with the assistants more natural.
4. Accessibility Tools: Whisper can be leveraged to develop accessibility tools that provide real-time captioning for individuals with hearing impairments. This can enhance accessibility in various settings, such as classrooms, conferences, and public events.
5. Media Translations: Media companies can utilize the Whisper model for automatic speech translation. This can facilitate the translation of spoken content in videos, podcasts, and other multimedia formats, making it accessible to a wider audience.

Please note that the model's performance may vary across languages and accents, and thorough evaluations in specific contexts and domains are recommended before deploying the model for real-world applications.
