# Model name

TrOCR (base-sized model, fine-tuned on SROIE)

## Links

Model Page: [https://huggingface.co/microsoft/trocr-base-printed](https://huggingface.co/microsoft/trocr-base-printed)

GitHub Repo: Not available

## Description

The TrOCR model is an encoder-decoder model that is fine-tuned on the SROIE dataset. It consists of an image Transformer as the encoder and a text Transformer as the decoder. The image encoder is initialized from the weights of BEiT, while the text decoder is initialized from the weights of RoBERTa. Images are presented to the model as a sequence of fixed-size patches (resolution 16x16) and are linearly embedded. The Transformer text decoder autoregressively generates tokens. The model is primarily designed for optical character recognition (OCR) on single text-line images, specifically for printed text.

## Usage example

To use this model with Python, you can use the `transformers` library:

```python
from transformers import TrOCRProcessor, VisionEncoderDecoderModel
from PIL import Image
import requests

# Load image from the IAM database
url = 'https://fki.tic.heia-fr.ch/static/img/a01-122-02-00.jpg'
image = Image.open(requests.get(url, stream=True).raw).convert("RGB")

processor = TrOCRProcessor.from_pretrained('microsoft/trocr-base-printed')
model = VisionEncoderDecoderModel.from_pretrained('microsoft/trocr-base-printed')
pixel_values = processor(images=image, return_tensors="pt").pixel_values

generated_ids = model.generate(pixel_values)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0]
```

## Intended uses & limitations

The TrOCR model can be used for optical character recognition (OCR) on single text-line images. It is designed for printed text and should be fine-tuned on specific tasks of interest. It is capable of recognizing characters in the given image and generating corresponding text output.
