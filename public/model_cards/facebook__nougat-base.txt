## Description

The Nougat Base-Sized Model is a neural model trained on PDF-to-markdown conversion. It is based on the Nougat: Neural Optical Understanding for Academic Documents paper by Blecher et al. and was first released in the Hugging Face repository. The model utilizes a vision encoder based on the Swin Transformer architecture and a text decoder based on the mBART model. Nougat is designed to autoregressively predict the markdown format from the pixels of a PDF image.

## Usage example

```python
from transformers import NougatForImageToMarkdown

nougat = NougatForImageToMarkdown.from_pretrained("facebook/nougat-base")
# Pass the PDF image to the model for conversion to markdown
markdown = nougat.predict(image)
```
