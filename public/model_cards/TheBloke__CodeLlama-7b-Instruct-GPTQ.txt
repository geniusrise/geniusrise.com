# Model name

CodeLlama-7B-Instruct-GPTQ

## Links

[Original Hugging Face Page](https://huggingface.co/TheBloke/CodeLlama-7B-Instruct-GPTQ)

## Description

CodeLlama-7B-Instruct-GPTQ is a text generation model based on the GPT architecture. It has been fine-tuned on the CodeLlama dataset and is designed to generate code that solves specific coding problems. The model takes a prompt in the form of a coding problem and generates code that meets the specified constraints and passes example test cases.

The model has been implemented using the Transformers library with Python. It has a total of 1,131,458,560 parameters. The model is part of the Llama family of models and is specifically built for text generation tasks.

## Usage example

```python
from transformers import GPTForCausalLM, GPTTokenizer

tokenizer = GPTTokenizer.from_pretrained("TheBloke/CodeLlama-7B-Instruct-GPTQ")
model = GPTForCausalLM.from_pretrained("TheBloke/CodeLlama-7B-Instruct-GPTQ")

prompt = "[INST] Write code to solve the following coding problem that obeys the constraints and passes the example test cases. Please wrap your code answer using ```:\n"
input_text = prompt + "Problem: [add problem description here]\nExample: [add example here]"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=100)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```

Note: The code example above assumes that you have already installed the Transformers library and have access to the model's pre-trained weights.
