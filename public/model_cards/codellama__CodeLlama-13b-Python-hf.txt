# Model name

CodeLlama-13b-Python-hf

## Links

[model page](https://huggingface.co/codellama/CodeLlama-13b-Python-hf)

## Description

CodeLlama-13b-Python-hf is a text generation model based on the Code Llama architecture. It has been trained using the transformers library in Python. The model has a total of 13 billion parameters.

The model is designed for text generation tasks and supports the GPTQ and AWQ frameworks. It is compatible with the transformers library in Python.

For more information about the model, please refer to the [model page](https://huggingface.co/codellama/CodeLlama-13b-Python-hf).

## Usage example

Here is an example of how to use the CodeLlama-13b-Python-hf model in Python with the transformers library:

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "codellama/CodeLlama-13b-Python-hf"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)

input_text = "Once upon a time"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=100)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```

Please note that the example above requires the transformers library in Python. You can install it using the following command:

```shell
pip install transformers
```
