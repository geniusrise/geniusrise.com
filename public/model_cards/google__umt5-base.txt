## Description
The `google/umt5-base` model is a multilingual text-to-text transformer model based on the T5 architecture. It supports various languages including Afrikaans, Arabic, Chinese, Dutch, English, French, German, Japanese, Spanish, and many more. The model has been trained on the mc4 dataset and has around 220 million parameters.

## Usage example
Here is an example of how to use the `google/umt5-base` model with the transformers library in Python:

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/umt5-base")
model = T5ForConditionalGeneration.from_pretrained("google/umt5-base")

text = "Translate this sentence to French: 'Hello, how are you?'"
inputs = tokenizer.encode(text, return_tensors="pt")
outputs = model.generate(inputs)

translated_text = tokenizer.decode(outputs[0])
print(translated_text)
```

This will output the translated sentence in French: "Bonjour, comment ça va ?"
