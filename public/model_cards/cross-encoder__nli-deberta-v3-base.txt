# Model name

cross-encoder/nli-deberta-v3-base

## Links

## Description

The cross-encoder/nli-deberta-v3-base model is a transformer-based model trained for natural language inference tasks. It is built using the Deberta-v3 architecture and is specifically designed for zero-shot classification tasks. The model performs inference and supports the use of the autotrain and endpoint features.

The model has been fine-tuned on the multi_nli and snli datasets and achieves high accuracy in zero-shot classification tasks. It uses the transformers library with Python for the examples.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("cross-encoder/nli-deberta-v3-base")
model = AutoModelForSequenceClassification.from_pretrained("cross-encoder/nli-deberta-v3-base")

sentence = "This is an example sentence."
inputs = tokenizer.encode_plus(sentence, add_special_tokens=True, return_tensors="pt")

outputs = model(**inputs)
logits = outputs.logits
```

The model can be used for various natural language inference tasks by providing input sentences and using the model's outputs for classification or further processing.
