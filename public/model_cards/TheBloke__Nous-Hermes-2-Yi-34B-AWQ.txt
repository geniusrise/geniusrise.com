## Description
Nous Hermes 2 Yi 34B is a state-of-the-art model fine-tuned on 1,000,000 entries of GPT-4 generated data as well as open datasets. It has been quantized to 4 bits using AWQ (Adaptive Weight Quantization), offering fast Transformers-based inference with equivalent or better quality compared to GPTQ. This model uses ChatML as the prompt format and is meant for text generation tasks. It comes with a total model size of 5.4B parameters and was quantized by TheBloke.

### Datasets
- VMware Open Instruct
- GPT-4 generated data

### Number of Parameters
- 5.4 billion

### Quantization
- AWQ (Adaptive Weight Quantization)

### Compatibility
- Linux and Windows
- NVidia GPUs only
- Text Generation Webui (Loader: AutoAWQ)
- vLLM version 0.2.2 or later
- Hugging Face Text Generation Inference (TGI) version 1.1.0 or later
- Transformers version 4.35.0 or later

## Usage example
**Using the Transformers Library with Python:**
```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TextGenerationPipeline

model_name_or_path = "TheBloke/Nous-Hermes-2-Yi-34B-AWQ"

tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)
model = AutoModelForCausalLM.from_pretrained(model_name_or_path)

text_generator = TextGenerationPipeline(model=model, tokenizer=tokenizer)

prompt = "The quick brown fox jumps over the lazy dog"
outputs = text_generator(prompt, max_length=50, do_sample=True, temperature=0.8)

print(outputs[0]["generated_text"])
```
Note: Replace the `model_name_or_path` with the actual model name or path. Adjust the parameters such as `max_length`, `do_sample`, and `temperature` as required for your use case.
