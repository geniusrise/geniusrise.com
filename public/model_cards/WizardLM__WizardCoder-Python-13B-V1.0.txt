# Model name

WizardCoder-Python-13B-V1.0

## Links
- [Model Page](https://huggingface.co/WizardLM/WizardCoder-Python-13B-V1.0)
- [GitHub Repo](https://github.com/WizardLP/WizardCoder)

## Description
WizardCoder-Python-13B-V1.0 is a large language model trained on Python code. It is based on the Llama architecture and is part of the transformers library. The model has been fine-tuned for text generation tasks and is particularly suited for code generation tasks in Python. It has been evaluated on the HumanEval dataset using the "pass@1" metric, achieving a value of 0.64. The model is publicly available and can be used with the transformers library in Python.

## Usage example
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "WizardLM/WizardCoder-Python-13B-V1.0"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

input_code = "def multiply(x, y):\n    return x * y\n"
input_tokenized = tokenizer.encode(input_code, return_tensors="pt")

output = model.generate(input_tokenized, max_length=100)

output_code = tokenizer.decode(output[0], skip_special_tokens=True)
print(output_code)
```

This example demonstrates how to use the WizardCoder-Python-13B-V1.0 model from the transformers library to generate Python code. The model takes a code snippet as input and generates a continuation of the code.
