# Model Name

financial-roberta-large-sentiment

## Links

- [Hugging Face Model Page](https://huggingface.co/soleimanian/financial-roberta-large-sentiment)

## Description

The financial-roberta-large-sentiment model is a sentiment analysis model trained on financial text data using the RoBERTa architecture. It is specifically designed for analyzing sentiment in financial statements, accounting, finance, business, CSR reports, financial news, earnings call transcripts, and sustainability-related texts. The model can be used for text classification tasks related to sentiment analysis in the financial domain. It is implemented in the transformers library in Python.

- Dataset: Financial text data
- Number of parameters: Large size
- Model architecture: RoBERTa
- Application: Sentiment analysis in the financial domain

## Usage Example

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer

model_name = "soleimanian/financial-roberta-large-sentiment"
model = AutoModelForSequenceClassification.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

text = "This company's financial performance is outstanding."
tokens = tokenizer(text, truncation=True, padding=True, return_tensors="pt")
input_ids = tokens.input_ids
attention_mask = tokens.attention_mask

output = model(input_ids=input_ids, attention_mask=attention_mask)
predicted_label = output.logits.argmax().item()

# 1: positive sentiment, 0: negative sentiment
sentiment = "Positive" if predicted_label == 1 else "Negative"
print(f"The sentiment of the text is {sentiment}.")
```
