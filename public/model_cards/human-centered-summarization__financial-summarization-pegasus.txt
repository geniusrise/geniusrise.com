# Model name

financial-summarization-pegasus

## Links

- [Hugging Face Model Page](https://huggingface.co/human-centered-summarization/financial-summarization-pegasus)

## Description

The financial-summarization-pegasus model is a Pegasus model fine-tuned for financial summarization tasks. It is developed by the Human Centered Summarization team. This model is trained to summarize financial news articles, making it ideal for tasks such as summarizing stocks, mergers, acquisitions, and financial reports. 

The model is based on the Pegasus architecture and is trained on the xsum dataset. It performs abstractive summarization and is evaluated using metrics such as ROUGE-1, ROUGE-2, ROUGE-L, and ROUGE-LSUM. The model has a total of 568,796,007 parameters.

## Usage example

You can use the financial-summarization-pegasus model with the transformers library in Python, as shown below:

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tokenizer = AutoTokenizer.from_pretrained("human-centered-summarization/financial-summarization-pegasus")
model = AutoModelForSeq2SeqLM.from_pretrained("human-centered-summarization/financial-summarization-pegasus")

text = "National Commercial Bank (NCB), Saudi Arabia’s largest lender by assets, agreed to buy rival Samba Financial Group for $15 billion in the biggest banking takeover this year. NCB will pay 28.45 riyals ($7.58) for each Samba share..."
inputs = tokenizer.encode(text, return_tensors="pt", truncation=True)

outputs = model.generate(inputs)
summary = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(summary)
```

This will generate a summary of a given financial news article using the financial-summarization-pegasus model.
