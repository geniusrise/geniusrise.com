# Model name

Llama-2-70B-GPTQ

## Links

- [Hugging Face Model Page](https://huggingface.co/TheBloke/Llama-2-70B-GPTQ)
- [GitHub Repository](https://github.com/TheBloke/llama-2-70b-gptq)

## Description

Llama-2-70B-GPTQ is a large-scale generative language model based on the Llama-2 architecture. It has been fine-tuned for text generation tasks using the GPTQ method. The model comes with a predefined prompt template that can be used for generating text.

The model has a total of 9,102,492,672 parameters and supports English language. It is compatible with the transformers library in Python.

## Usage example

Here's an example of how to use the Llama-2-70B-GPTQ model with the transformers library in Python:

```python

from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/Llama-2-70B-GPTQ"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

prompt = "My name is John and"

inputs = tokenizer(prompt, return_tensors="pt")
outputs = model.generate(inputs.input_ids)

generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```

```shell
pip install transformers
```
