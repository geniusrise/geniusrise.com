## Description

The `tapas-small-finetuned-wikisql-supervised` model is a fine-tuned version of the Tapas model trained on the WikiSQL dataset. It is part of the Google models. The model is based on the Transformers library and is available for both PyTorch and TensorFlow. It is designed for table question-answering tasks and can process tabular data with natural language queries.

The model has been trained with a supervised learning approach, where it learns from examples that include both table content and corresponding SQL queries. It has achieved good performance on the WikiSQL dataset, which is a commonly used benchmark for table question-answering tasks.

The model has a small size and a moderate number of parameters. It can be used for a wide range of table question-answering tasks, such as answering questions about tabular data or generating SQL queries based on natural language queries.
