# Model name

flan-t5-xl

## Links

- [Model Page](https://huggingface.co/google/flan-t5-xl)
- [Github Repo](https://github.com/google/flan)

## Description

flan-t5-xl is a Text-to-Text Transfer Transformer (T5) model developed by Google. It is trained to perform various natural language processing tasks such as text generation, summarization, translation, question answering, logical reasoning, scientific knowledge, and more. The model is based on the T5 architecture and is available in English, French, German, Romanian, and as a multilingual model. It has been fine-tuned on datasets such as SVAKUL@ECNU's QReCC, Taskmaster2, Djaym7's WikiDialog, DeepMind's Code Contests, Lambada, GSM8k, Aqua_rat, ESNLI, QUASC, and QED.

The model can be used with the transformers library in Python.

## Usage example

Here is an example of using the flan-t5-xl model for translation from English to German:

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/flan-t5-xl")
model = T5ForConditionalGeneration.from_pretrained("google/flan-t5-xl")

text = "Translate to German: My name is Arthur"
inputs = tokenizer.encode("translate English to German: " + text, return_tensors="pt")
outputs = model.generate(inputs, max_length=300, num_beams=4)

translated_text = tokenizer.decode(outputs[0])

print(translated_text)
```

This will output the translated text: "Mein Name ist Arthur."

Please note that the above is just an example, and the model can be used for various NLP tasks by adjusting the input and the prefix accordingly.
