# Model name
google/flan-t5-xl

## Links
- [Hugging Face Model Page](https://huggingface.co/google/flan-t5-xl)

## Description
The `google/flan-t5-xl` model is a large-scale text-to-text transformer model developed by Google. It is built on the T5 (Text-To-Text Transfer Transformer) architecture and is specifically designed for text generation tasks. The model has been fine-tuned on various datasets and supports multiple languages (English, French, Romanian, German, and multilingual).

## Usage example
```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/flan-t5-xl")
model = T5ForConditionalGeneration.from_pretrained("google/flan-t5-xl")

input_text = "Translate to German: My name is Arthur"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```

Please note that this is just a simple usage example, and the model can be used for various other text generation tasks as well.

The model has been trained on several datasets, including `svakulenk0/qrecc`, `taskmaster2`, `djaym7/wiki_dialog`, `deepmind/code_contests`, `lambada`, `gsm8k`, `aqua_rat`, `esnli`, `quasc`, and `qed`.

The model has a total of 2,849,757,184 parameters.

For more information and details about the model, please refer to the [Hugging Face Model Page](https://huggingface.co/google/flan-t5-xl).
