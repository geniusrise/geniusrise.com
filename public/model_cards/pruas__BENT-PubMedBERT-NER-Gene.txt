## Description

BENT-PubMedBERT-NER-Gene is a token classification model based on the BERT architecture trained on the PubMed dataset for named entity recognition (NER) tasks related to gene entities. The model is implemented using the transformers library in Python and utilizes the BERT architecture. It has a total of 556 downloads and 9 likes.

The model is specifically designed for NER tasks related to gene entities in biomedical texts. It has been fine-tuned on the PubMed dataset, which contains a vast collection of scientific articles in the biomedical domain. The model can be used to extract gene names and identify their corresponding spans in biomedical text.

## Usage example

Here is an example of how to use the BENT-PubMedBERT-NER-Gene model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification

# Load the tokenizer and model
tokenizer = AutoTokenizer.from_pretrained("pruas/BENT-PubMedBERT-NER-Gene")
model = AutoModelForTokenClassification.from_pretrained("pruas/BENT-PubMedBERT-NER-Gene")

# Tokenize input text
text = "...insert your input text here..."
inputs = tokenizer.encode_plus(text, return_tensors="pt")

# Perform inference
outputs = model(**inputs)

# Get predicted labels
predicted_labels = tokenizer.batch_decode(outputs.logits.argmax(dim=2))

# Print the predicted labels
print(predicted_labels)
```
