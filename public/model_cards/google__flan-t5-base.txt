# Model name

flan-t5-base

## Links

**Model page**: [flan-t5-base](https://huggingface.co/google/flan-t5-base)

## Description

flan-t5-base is a T5-based model developed by Google. It is designed for text-to-text generation tasks and supports multiple languages, including English, French, German, Romanian, and multilingual tasks. This model is trained using the T5 architecture and is available for use with the Transformers library in Python.

The model has been trained on several datasets, including svakulenk0/qrecc, taskmaster2, djaym7/wiki_dialog, deepmind/code_contests, lambada, gsm8k, aqua_rat, esnli, quasc, and qed.

With a total of 247,577,856 parameters, flan-t5-base can be used for various tasks, such as summarization, translation, question answering, logical reasoning, scientific knowledge, boolean expressions, math reasoning, and premise and hypothesis tasks.

## Usage example

Here is an example of how to use the flan-t5-base model with the Transformers library in Python:

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/flan-t5-base")
model = T5ForConditionalGeneration.from_pretrained("google/flan-t5-base")

input_text = "Translate to German: My name is Arthur"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)

translated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(translated_text)
```

This example demonstrates how to use the translation capability of the flan-t5-base model to translate the input English text to German.
