# Model name

The model name is Llama-2-13B-GPTQ.

## Links

You can find the model on [Hugging Face](https://huggingface.co/TheBloke/Llama-2-13B-GPTQ).

## Description

Llama-2-13B-GPTQ is a text generation model trained on the Llama-2 dataset. It is based on the GPTQ architecture and is fine-tuned for text-generation tasks. The model has a total of 2,029,493,760 parameters.

## Usage example

You can use the Llama-2-13B-GPTQ model with the transformers library in Python. Here's an example:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("TheBloke/Llama-2-13B-GPTQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/Llama-2-13B-GPTQ")

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=50)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```

This example generates text starting from the prompt "Once upon a time," using the Llama-2-13B-GPTQ model.
