# Model name

The model is called "Llama-2-13B-GPTQ".

## Links

- [Hugging Face Model Page](https://huggingface.co/TheBloke/Llama-2-13B-GPTQ)
- [GitHub Repository](https://github.com/TheBloke/Llama-2-13B-GPTQ)

## Description

The Llama-2-13B-GPTQ model is a text-generation model based on the Llama-2 architecture. It is trained on a large dataset and has a total of 13 billion parameters. The model is implemented using the transformers library in Python. It is suitable for various natural language processing tasks, particularly text generation.

The model utilizes GPTQ (Generative Pre-trained Transformer-Quality) techniques to generate high-quality text. It has been fine-tuned and optimized for performance, making it suitable for both developers and builders.

## Usage example

Here is an example of how to use the Llama-2-13B-GPTQ model with the transformers library in Python:

```python
from transformers import LlamaForCausalLM, LlamaTokenizer

model_name = "TheBloke/Llama-2-13B-GPTQ"
tokenizer = LlamaTokenizer.from_pretrained(model_name)
model = LlamaForCausalLM.from_pretrained(model_name)

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_text)
```

This will generate text based on the given input text using the Llama-2-13B-GPTQ model.

Please note that the model requires the transformers library and the specific Llama-2-13B-GPTQ model package to be installed in order to run the example code.
