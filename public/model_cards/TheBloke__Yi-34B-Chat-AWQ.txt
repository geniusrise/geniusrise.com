## Description

The Yi-34B-Chat-AWQ model is a text generation model that is based on the Llama architecture. It is trained to generate text based on user prompts. The model has been quantized using the AWQ (Approximate Weight Quantization) method, resulting in reduced memory requirements and improved efficiency. The model is suitable for various applications that require text generation.

The model is created by TheBloke and is part of the 01-ai organization.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("TheBloke/Yi-34B-Chat-AWQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/Yi-34B-Chat-AWQ")

input_text = "Hello! How can I assist you today?"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_text)
```

Please note that in this example, we are using the transformers library in Python to load the model and tokenizer. The input text is encoded using the tokenizer, and then passed to the model for text generation. The generated text is then decoded using the tokenizer to obtain the final output.
