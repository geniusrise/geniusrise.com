# Model name
Mixtral_11Bx2_MoE_19B-AWQ

## Links
[Link to the original Hugging Face page](https://huggingface.co/TheBloke/Mixtral_11Bx2_MoE_19B-AWQ)

## Description
The Mixtral_11Bx2_MoE_19B-AWQ model is a text generation model trained on the Mixtral dataset. It has a total of 2,794,852,352 parameters and follows the AutoModelForCausalLM architecture. The model type is "mixtral" and it is compatible with the transformers library in Python. The model uses 4-bit precision and the AWQ (Arithmetic-weighted Quantization) quantization method. The license for this model is cc-by-nc-4.0. This model is based on the base model cloudyu/Mixtral_11Bx2_MoE_19B.

## Usage example
```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("TheBloke/Mixtral_11Bx2_MoE_19B-AWQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/Mixtral_11Bx2_MoE_19B-AWQ")

text = "I love to"
input_ids = tokenizer.encode(text, return_tensors="pt")
output = model.generate(input_ids, max_length=100)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```
