## Description

The Mixtral_11Bx2_MoE_19B-AWQ model is a text generation model powered by the Mixtral architecture. It has been trained on a dataset and offers support for both GPTQ and AWQ.

The model has a total of 2,794,852,352 parameters. It is based on the cloudyu/Mixtral_11Bx2_MoE_19B base model and is fine-tuned for text generation.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/Mixtral_11Bx2_MoE_19B-AWQ"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids, max_length=50)

output_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(output_text)
```

This code example demonstrates how to use the Mixtral_11Bx2_MoE_19B-AWQ model for text generation. It generates a continuation for the input prompt "Once upon a time," with a maximum output length of 50 tokens.
