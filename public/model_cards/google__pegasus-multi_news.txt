## Description

The google/pegasus-multi_news model is a Pegasus model for multi-document summarization. It is trained on a large dataset and uses the transformers library with Python for implementation. The model is designed for performing text-to-text generation tasks, specifically summarization. It has a pipeline tag of "summarization" and is compatible with AutoTrain and inference endpoints. The model has been downloaded 2483 times and has received 13 likes.

## Usage example

```python
from transformers import PegasusTokenizer, PegasusForConditionalGeneration

model_name = "google/pegasus-multi_news"

tokenizer = PegasusTokenizer.from_pretrained(model_name)
model = PegasusForConditionalGeneration.from_pretrained(model_name)

text = "Input text to be summarized."
input_ids = tokenizer.encode(text, truncation=True, max_length=512, return_tensors="pt")
output = model.generate(input_ids, max_length=150, num_beams=4, early_stopping=True)
summary = tokenizer.decode(output[0], skip_special_tokens=True)

print(f"Input text: {text}")
print(f"Summary: {summary}")
```
