## Description

starchat-beta-GPTQ is a text generation model based on the GPTBigCodeForCausalLM architecture. It is designed for text generation tasks and is compatible with the transformers library. The model has a total of 2,556,054,784 parameters. It is built using the transformers library in Python.

The model is tagged with "text-generation" and "transformers" among other tags. It is trained with the "bigcode-openrail-m" license. The model supports 4-bit precision and is trained in the US region.

## Usage example

```python
from transformers import GPTBigCodeForCausalLM, AutoTokenizer

model_name = "TheBloke/starchat-beta-GPTQ"
model = GPTBigCodeForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

input_text = "Hello, how are you?"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_text)
```

This code snippet shows how to use the starchat-beta-GPTQ model for text generation. The input text is encoded using the model's tokenizer, and then passed to the model to generate output text. The generated text is then decoded using the tokenizer.
