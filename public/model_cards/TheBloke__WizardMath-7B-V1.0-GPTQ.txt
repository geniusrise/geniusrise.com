# Model name

WizardMath-7B-V1.0-GPTQ

## Links

- [Model page](https://huggingface.co/TheBloke/WizardMath-7B-V1.0-GPTQ)
- [GitHub repo](https://github.com/TheBloke/WizardMath-7B-V1.0-GPTQ)

## Description

The WizardMath-7B-V1.0-GPTQ model is a text generation model trained on the WizardMath dataset. The model has been fine-tuned using the GPTQ algorithm. It has a total of 816,963,584 parameters. The model is built using the transformers library with Python.

## Usage example

```python
from transformers import GPT2LMTokenizer, GPT2LMModel

tokenizer = GPT2LMTokenizer.from_pretrained("TheBloke/WizardMath-7B-V1.0-GPTQ")
model = GPT2LMModel.from_pretrained("TheBloke/WizardMath-7B-V1.0-GPTQ")

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

output = model.generate(input_ids, max_length=100)

print(tokenizer.decode(output[0], skip_special_tokens=True))
```

This model can be used to generate text based on a given prompt. The example code above shows how to use the model for text generation.
