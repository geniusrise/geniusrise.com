# Model name

Bagel DPO 34B v0.2 - AWQ by Jon Durbin

## Links
- [Hugging Face Model Page](https://huggingface.co/TheBloke/bagel-dpo-34b-v0.2-AWQ)
- [Original Model by Jon Durbin](https://huggingface.co/jondurbin/bagel-dpo-34b-v0.2)

## Description
This repository contains the AWQ (Adaptive Weight Quantization) model files for Jon Durbin's Bagel DPO 34B v0.2. The AWQ method supports 4-bit quantization offering fast Transformers-based inference with equivalent or better quality compared to common GPTQ (General Purpose Transformer Quantization) settings.

- **Datasets used include**: ai2_arc, spicy-3.1, codeparrot/apps, facebook/belebele, boolq, cinematika-v0.1, drop, lmsys-chat-1m, MathInstruct, mmlu, natural-instructions, openbookqa, piqa, Tested-22k-Python-Alpaca, rosetta-code, SlimOrca, spider, squad_v2, Synthia-v1.3, winogrande, HelpSteer, orca_dpo_pairs, toxic-dpo-v0.1, truthy-dpo-v0.1, and ultrafeedback_binarized_cleaned.
- **Parameters**: Approximately 5.4 billion
- **AWQ Parameters**: Quantization with 4 bits and a group size of 128 using VMware Open Instruct dataset. Total size being 19.23 GB.

The model supports GPU inference on Linux and Windows platforms with NVidia GPUs. It is compatible with software like Text Generation Webui using AutoAWQ loader, vLLM version 0.2.2 and later for servers, Hugging Face Text Generation Inference (TGI) version 1.1.0 and later, and can also be utilized in code via Transformers library version 4.35.0 and later.

## Usage example

### Python Code Using Transformers Library
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name_or_path = "TheBloke/bagel-dpo-34b-v0.2-AWQ"

tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)
model = AutoModelForCausalLM.from_pretrained(
    model_name_or_path,
    device_map="auto"
)

prompt = "Tell me about coffee"  # example prompt

inputs = tokenizer(prompt, return_tensors="pt")
generation_params = {
    "max_new_tokens": 50,  # number of generated tokens
    "do_sample": True,     # whether to use sampling
    "top_k": 50,           # the K value for Top-K sampling
}

# Generate text
output = model.generate(**inputs, **generation_params)
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

print(generated_text)
```
Replace `'auto'` in `device_map` with specific GPU device ID(s) where necessary (e.g., `"cuda:0"`) depending on the system's configuration.
