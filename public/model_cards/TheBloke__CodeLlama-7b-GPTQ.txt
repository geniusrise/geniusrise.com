# Model name
CodeLlama-7B-GPTQ

## Links
- [Model Page](https://huggingface.co/TheBloke/CodeLlama-7B-GPTQ)

## Description
CodeLlama-7B-GPTQ is a text generation model based on the GPT architecture. It is trained on various code-related datasets and has a total of 816,963,584 parameters. The model is designed specifically for generating code and can be fine-tuned for different tasks. It uses the transformers library in Python for its implementation.

## Usage example
Here is an example of how to use CodeLlama-7B-GPTQ with the transformers library in Python:

```python
from transformers import GPT2Tokenizer, GPT2LMHeadModel

tokenizer = GPT2Tokenizer.from_pretrained("TheBloke/CodeLlama-7B-GPTQ")
model = GPT2LMHeadModel.from_pretrained("TheBloke/CodeLlama-7B-GPTQ")

input_text = "def hello_world():\n    print('Hello, World!')"

input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids, max_length=100)

decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
```

This will generate code based on the input text provided and print the result.

Please note that the model is licensed under LLAMA 2.0 and the prompt template for generating code is "{prompt}\n". For more details and usage options, refer to the [original Hugging Face page](https://huggingface.co/TheBloke/CodeLlama-7B-GPTQ).
