# Model name

flan-t5-large

## Links

- [Hugging Face Model Page](https://huggingface.co/google/flan-t5-large)

## Description

flan-t5-large is a T5 model developed by Google. It is designed for text-to-text generation tasks and belongs to the transformers library. The model has been fine-tuned on various datasets, including svakulenk0/qrecc, taskmaster2, djaym7/wiki_dialog, deepmind/code_contests, lambada, gsm8k, aqua_rat, esnli, quasc, and qed. It supports multiple languages, including English, French, Romanian, and German. The model is licensed under Apache-2.0.

## Usage example

Here is an example of using the flan-t5-large model with the transformers library in Python:

```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

model_name = "google/flan-t5-large"
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

inputs = tokenizer.encode_plus(
    "Translate to German: My name is Arthur",
    return_tensors="pt",
    padding="max_length",
    max_length=128,
)

outputs = model.generate(
    inputs["input_ids"],
    attention_mask=inputs["attention_mask"],
    num_beams=4,
    max_length=128,
)

translated_text = tokenizer.decode(outputs[0])
print(translated_text)
```

This example demonstrates using the model for translation from English to German. The generated output represents the translated text.
