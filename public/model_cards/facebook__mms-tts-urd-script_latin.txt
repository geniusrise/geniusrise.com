# Model name

Massively Multilingual Speech (MMS): Urdu Text-to-Speech

## Links

- Model page: [Facebook MMS-TTS Urdu Script Latin](https://huggingface.co/facebook/mms-tts-urd-script_latin)
- GitHub repository: [Facebook MMS-TTS](https://github.com/huggingface/transformers/tree/master/examples/research_projects/massively_multilingual_speech)

## Description

The Massively Multilingual Speech (MMS) Urdu Text-to-Speech (TTS) model checkpoint is part of Facebook's MMS project. It is an end-to-end speech synthesis model that predicts a speech waveform given an input text sequence. The model architecture includes a posterior encoder, decoder, and conditional prior, forming a conditional variational autoencoder (VAE). The spectrogram-based acoustic features are predicted using a flow-based module consisting of a Transformer-based text encoder and multiple coupling layers. The spectrogram is then decoded using a stack of transposed convolutional layers. The model also includes a stochastic duration predictor, allowing for the synthesis of speech with different rhythms from the same input text. The training of the model involves a combination of losses derived from variational lower bound and adversarial training. Normalizing flows are applied to the conditional prior distribution to improve expressiveness.

## Usage example

To use the MMS-TTS Urdu Text-to-Speech model, you need to install the Transformers library version 4.33 or later:

```python
pip install --upgrade transformers accelerate
```

Then, you can run the following code snippet for inference:

```python
from transformers import VitsModel, AutoTokenizer
import torch

model = VitsModel.from_pretrained("facebook/mms-tts-urd-script_latin")
tokenizer = AutoTokenizer.from_pretrained("facebook/mms-tts-urd-script_latin")

text = "some example text in the Urdu language"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    output = model(**inputs).waveform
```

The resulting waveform can be saved as a .wav file or displayed in a Jupyter Notebook / Google Colab.

## Use cases

- Localization: The model can be used to convert written text in Urdu to natural-sounding speech, enabling localization of products, services, and digital content in the Urdu language.
- Accessibility: By converting text to speech, the model can facilitate access to information for individuals with visual impairments, allowing them to hear the content in the Urdu language.
- Virtual Assistants: The MMS-TTS model can be used to power virtual assistants, chatbots, or voice-enabled applications that require generating spoken responses in the Urdu language.
- Audiobooks and Podcasts: The model can be utilized for generating audio versions of books, articles, or other text-based content, making them accessible and convenient for consumption.
- Language Learning: The MMS-TTS model can be employed in language learning applications to provide spoken examples and pronunciation guides in the Urdu language.
