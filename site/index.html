Run open AI models
on your own infrastructure

One binary. One yaml file. One OpenAI-compatible endpoint that autoscales inside your budget — no kubernetes, no nat gateways, no hosted backend.

curl -fsSL https://geniusrise.com/install.sh | sh
geniusrise init
geniusrise plan
geniusrise apply

then point any OpenAI-compatible client at your endpoint with an api key. llms, speech-to-text and text-to-speech.

simplest frontend

A local gui and a three-command cli. Your deploy.yaml is the only state you own: a list of models, api keys and one budget number.

most optimized runtime

A curated recipe catalog picks the tested engine — vLLM, llama.cpp or speaches — the right quantization and the cheapest gpu class for the capacity mode.

hard budget cap

Alert at 80% of the monthly budget, freeze scale-ups at 90%, scale everything to zero at 95%. Spot with on-demand fallback included.

zero-trust nodes

GPU nodes open no inbound ports anywhere. They dial the gateway out over mTLS — so homelabs and isp boxes behind NAT work too.

your keys stay yours

There is no geniusrise saas. Credentials live on your machine and in your own cloud. Nothing about you is stored by us.

for communities

Local providers, schools and companies can host models for their people the way cable tv once distributed channels — with an api key each.

Start in minutes

geniusrise init            # provider, region, budget, models
geniusrise plan --compare  # cost across clouds, no account needed
geniusrise apply           # gateway bootstraps in your cloud
