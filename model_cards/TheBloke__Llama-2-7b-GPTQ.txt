Llama-2-7B-GPTQ

## Description

Llama-2-7B-GPTQ is a language model based on the Llama-2-7B model, implemented using the transformers library in Python. The model is designed for text generation tasks and belongs to the text-generation pipeline. It has been fine-tuned with a base model of meta-llama/Llama-2-7b-hf. The model is quantized using the GPTQ (GPT Quantization) technique.

The model was created by Tom Jobbins (@TheBloke) and is available under the llama2 license.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "TheBloke/Llama-2-7B-GPTQ"
model = AutoModelForCausalLM.from_pretrained(model_name)

tokenizer = AutoTokenizer.from_pretrained(model_name)
input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
output = model.generate(input_ids)
generated_text = tokenizer.decode(output[0])

print(generated_text)
```

Note: Replace `model_name` with the actual model name you want to use.

The example showcases how to generate text using the Llama-2-7B-GPTQ model with the transformers library.
