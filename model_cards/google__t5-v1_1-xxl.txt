# Model name
google/t5-v1_1-xxl

## Links
- [Model Page](https://huggingface.co/google/t5-v1_1-xxl)
- [GitHub Repository](https://github.com/google-research/text-to-text-transfer-transformer)

## Description
The google/t5-v1_1-xxl model is based on the T5 architecture and is designed for text-to-text generation tasks. It is trained using the transformers library with Python. The model has a large number of parameters and is capable of performing text generation tasks such as summarization, translation, and question answering. The model's training data includes the C4 dataset. It supports both PyTorch and TensorFlow libraries.

## Usage example
```python
from transformers import T5Tokenizer, TFT5ForConditionalGeneration

tokenizer = T5Tokenizer.from_pretrained("google/t5-v1_1-xxl")
model = TFT5ForConditionalGeneration.from_pretrained("google/t5-v1_1-xxl")

input_text = "Translate this English text to French."
input_ids = tokenizer.encode(input_text, return_tensors="tf")
outputs = model.generate(input_ids)
output_text = tokenizer.decode(outputs[0])

print(output_text)
```
