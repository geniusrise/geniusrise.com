# Mixtral-8x7B-Instruct-v0.1

## Links

- [Hugging Face Model Page](https://huggingface.co/mistralai/Mixtral-8x7B-Instruct-v0.1)

## Description

The Mixtral-8x7B, developed by Mistral AI, is a Large Language Model pretrained as a Sparse Mixture of Experts. The model has demonstrated superior performance compared to Llama 2 70B on several benchmarks. It is based on the original Mixtral torrent release with different file format and parameter names. The model can't be instantiated using Hugging Face at the current stage.

The model requires a specific instruction format to generate optimal outputs. The prompts for the Instruct model follow a specific pattern defined as - `<s> [INST] Instruction [/INST] Model answer</s> [INST] Follow-up instruction [/INST]`. Other tokens like [INST], [/INST], <s> and </s> are regular strings while BOS and EOS tokens denote the beginning and end of a string.

## Usage Example

The model can be used in a Python environment with the transformers library as such:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "mistralai/Mixtral-8x7B-Instruct-v0.1"
tokenizer = AutoTokenizer.from_pretrained(model_id)

model = AutoModelForCausalLM.from_pretrained(model_id)

text = "Hello my name is"
inputs = tokenizer(text, return_tensors="pt")

outputs = model.generate(**inputs, max_new_tokens=20)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

It is possible to reduce the memory requirements through optimizations, including running the model in half-precision (only compatible with GPU devices) or lower precision using 8-bit & 4-bit bitsandbytes. The model can also be loaded with Flash Attention 2.

The Mixtral-8x7B model currently doesn't have any moderation mechanisms, implying a lack of finer control over the content generated by the model. 

The Mixtral-8x7B model can be utilised for various business use cases such as:
1. Natural Language Understanding (NLU): With a scenario-specific pre-training, the model can be adapted to understand context from text data, opening avenues for sentiment analysis, contextual search, and text classification.
2. Content Generation: The model can be a tool for content generators, helping in blog generation, article ideation, and error-free writing assistance.
3. Personalized Customer Support: The model can provide AI assistance for Customer Support services, offering personalized and instantaneous support to queries.
