# Model name

WizardLM/WizardLM-70B-V1.0

## Links

- [Model Page](https://huggingface.co/WizardLM/WizardLM-70B-V1.0)
- [GitHub Repo](https://github.com/WizardLM/WizardLM-70B)

## Description

The WizardLM/WizardLM-70B-V1.0 is a language model powered by the Transformer architecture and trained using the GPT-Q framework. It is designed for text generation tasks and is compatible with the transformers library in Python. 

This model has a total of 70 billion parameters and is trained to follow complex instructions using the Wizard of Wikipedia dataset. It is suitable for builders and developers seeking a powerful language model for text generation tasks.

## Usage example

To use this model, you can install the transformers library in Python and load the model using its name:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("WizardLM/WizardLM-70B-V1.0")
model = AutoModelForCausalLM.from_pretrained("WizardLM/WizardLM-70B-V1.0")
```

You can then use the model for various text generation tasks, such as generating text based on prompts or completing sentences.
