## Description

The Llama-2-7B-Chat-GPTQ model is a text generation model based on the Llama-2 architecture. It is designed to generate helpful and respectful responses while ensuring safety. The model's prompt template includes guidelines for generating responses that are socially unbiased and positive. The model utilizes the transformers library in Python and has a quantization configuration of 4-bit precision.

The model is licensed under Llama 2 and is suitable for builders and developers looking to generate helpful and safe text responses.

## Usage example

```python
from transformers import pipeline

generator = pipeline("text-generation", model="TheBloke/Llama-2-7B-Chat-GPTQ")
prompt = "My name is John and I need help with"
response = generator(prompt, max_length=100)[0]["generated_text"]
print(response)
```

Please note that the example above uses the transformers library in Python to interact with the Llama-2-7B-Chat-GPTQ model for text generation.
