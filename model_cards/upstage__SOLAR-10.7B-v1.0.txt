# Model name

SOLAR-10.7B-v1.0

## Links

- [Model Page](https://huggingface.co/upstage/SOLAR-10.7B-v1.0)
- [GitHub Repository](https://github.com/upstage-ai/)

## Description

The SOLAR-10.7B-v1.0 model is a large language model trained with the Transformers library in Python. It is designed for text generation tasks and falls under the llama architecture. The model has been trained on a large dataset and has a total of 10,731,524,096 parameters. It is compatible with transformers, Safetensors, and llama libraries. The model supports text generation inference and has been trained on the US region.

## Usage example

Here is an example of how to use the SOLAR-10.7B-v1.0 model with the Transformers library in Python:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("upstage/SOLAR-10.7B-v1.0")
model = AutoModelForCausalLM.from_pretrained("upstage/SOLAR-10.7B-v1.0")

prompt = "Once upon a time,"
inputs = tokenizer.encode(prompt, return_tensors="pt")
outputs = model.generate(inputs, max_length=50)

decoded_outputs = tokenizer.decode(outputs[0])
print(decoded_outputs)
```

This will generate text based on the provided prompt using the SOLAR-10.7B-v1.0 model.
