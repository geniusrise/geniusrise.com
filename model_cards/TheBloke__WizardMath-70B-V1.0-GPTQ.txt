# Model name

The model is called WizardMath-70B-V1.0-GPTQ.

## Links

- [Model Page](https://huggingface.co/TheBloke/WizardMath-70B-V1.0-GPTQ)
- [GitHub Repository](https://github.com/TheBloke/models)

## Description

The WizardMath-70B-V1.0-GPTQ model is a large language model based on the GPT architecture. It is built using the Transformers library with Python. The model is trained on mathematical tasks and is designed to generate responses that appropriately complete the given instructions.

The model has a base model called WizardLM/WizardMath-70B-V1.0 and is quantized by TheBloke. It supports text generation using GPTQ (Quantized GPT) and AWQ (Adversarially Weight Quantized) methods. The model has a total of 9,102,520 parameters.

## Usage example

Here is an example of how to use the WizardMath-70B-V1.0-GPTQ model with the Transformers library in Python:

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

model_name = "TheBloke/WizardMath-70B-V1.0-GPTQ"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)

prompt = "Please solve the equation: x + 5 = 10"
input_ids = tokenizer.encode(prompt, return_tensors="pt")
output = model.generate(input_ids, max_length=50)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(generated_text)
```

This example demonstrates how to generate a response for an instruction to solve the equation "x + 5 = 10". The model will generate a response that appropriately completes the task.
