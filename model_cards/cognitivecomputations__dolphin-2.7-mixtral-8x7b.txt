## Description
The 'cognitivecomputations/dolphin-2.7-mixtral-8x7b' model is a text generation model built using the transformers library. It is a Mixtral model designed for text generation tasks. The model utilizes the GPTQ algorithm and has been trained on various datasets. It has a total of 3,252 downloads and 81 likes.

## Usage example
```python
from transformers import pipeline, AutoModelForCausalLM, AutoTokenizer

model_name = "cognitivecomputations/dolphin-2.7-mixtral-8x7b"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)
text_generator = pipeline("text-generation", model=model, tokenizer=tokenizer)

prompt = "Once upon a time,"
output = text_generator(prompt, max_length=100, num_return_sequences=1)

print(output[0]['generated_text'])
```

Please note that the above example assumes you have the transformers library installed. You can install it using `pip install transformers`.
