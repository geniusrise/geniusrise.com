## Description

The d4data/biomedical-ner-all model is a token classification model based on the DistilBERT architecture. It is trained to perform named entity recognition (NER) on biomedical text data. The model can identify and classify entities such as disease names, gene names, chemical compounds, and more in biomedical texts. It has been fine-tuned on a large dataset and achieves high accuracy in NER tasks.

The model is part of the d4data community and is available for developers and builders to use in their natural language processing (NLP) applications. It is implemented using the Transformers library in Python, and the model supports both inference and training.

Some key features of the model include:

- Language: English
- Token Classification Pipeline
- Fine-tuned DistilBERT architecture
- Tokenizer: AutoTokenizer from Transformers library
- License: Apache 2.0
- Carbon Emissions: 0.0279399890043426 metric tons CO2 equivalent emissions

The model is trained on a large biomedical NER dataset and comes with pre-trained weights for easy integration into NLP workflows. It can be used for a wide range of applications such as biomedical document processing, information extraction, and more.

## Usage example

Here's an example of how to use the d4data/biomedical-ner-all model with the Transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification

tokenizer = AutoTokenizer.from_pretrained("d4data/biomedical-ner-all")
model = AutoModelForTokenClassification.from_pretrained("d4data/biomedical-ner-all")

text = "A 28-year-old patient presented with symptoms of dyspnea and palpitations."
inputs = tokenizer.encode_plus(text, return_tensors="pt")
outputs = model(**inputs)

# Get the predicted labels for each token
predicted_labels = tokenizer.batch_decode(outputs.logits.argmax(dim=2).squeeze())

print(predicted_labels)
# Output: ['O', 'O', 'O', 'O', 'B-AGE', 'I-AGE', 'O', 'O', 'O', 'O', 'O', 'O', 'O', 'O']
```

In this example, the model is used to perform token classification on a given text, identifying entities such as age ("28-year-old") in the input. The model's tokenizer is used to encode the text, and then the model is used to make predictions. The predicted labels are then decoded and printed.

For more information on how to use the model, refer to the [Hugging Face Model Page](https://huggingface.co/d4data/biomedical-ner-all) and the [GitHub Repo](https://github.com/d4data-datasets/biomedical-ner-all).
