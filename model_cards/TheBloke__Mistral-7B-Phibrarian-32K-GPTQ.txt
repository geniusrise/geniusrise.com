## Description
The Mistral-7B-Phibrarian-32K-GPTQ model is a text generation model built using the Mistral architecture. It has been trained specifically for the task of text generation and is designed to provide advanced capabilities in this domain. The model has been quantized by TheBloke and includes 4-bit precision. It is available for use with the Transformers library in Python.

The model is based on the `emrgnt-cmplxty/Mistral-7b-Phibrarian-32k` base model and is licensed under llama2. It is compatible with the AutoTrain feature and is suitable for use in various text generation applications. The dataset used for training is C4.

The model has a total of 1,198,788,608 parameters.

## Usage example
You can use the Mistral-7B-Phibrarian-32K-GPTQ model with the Transformers library in Python. Here is an example code snippet:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("TheBloke/Mistral-7B-Phibrarian-32K-GPTQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/Mistral-7B-Phibrarian-32K-GPTQ")

input_text = "Once upon a time,"
input_ids = tokenizer.encode(input_text, return_tensors="pt")
generated_text = model.generate(input_ids, max_length=100)

print(tokenizer.decode(generated_text[0], skip_special_tokens=True))
```
