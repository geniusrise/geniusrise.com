## Description

The NSFW_text_classifier is a text classification model that can be used to identify and classify text that contains NSFW (Not Safe for Work) content, such as inappropriate or spam content. It is based on the DistilBERT architecture and trained using the transformers library with Python. The model supports inference and is compatible with auto-training and inference endpoints.

## Usage example

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

tokenizer = AutoTokenizer.from_pretrained("michellejieli/NSFW_text_classifier")
model = AutoModelForSequenceClassification.from_pretrained("michellejieli/NSFW_text_classifier")

# Preprocess input text
inputs = tokenizer("I like you. You remind me of me when I was young and stupid.", return_tensors="pt")

# Perform inference
outputs = model(**inputs)
predictions = outputs.logits.argmax().item()

print("Predicted class:", predictions)
```
