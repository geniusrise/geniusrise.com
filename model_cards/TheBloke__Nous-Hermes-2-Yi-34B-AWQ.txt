# Nous Hermes 2 Yi 34B - AWQ

## Links
- [Model Page](https://huggingface.co/TheBloke/Nous-Hermes-2-Yi-34B-AWQ)

## Description
Nous Hermes 2 Yi 34B AWQ is an LTS model generated by NousResearch and refined by TheBloke using AWQ (Accurate and blazing-fast low-bit weight Quantization) aiding faster transformers-based inference with better or equivalent quality compared to most GPTQ settings. This efficient 4-bit quantization model implementation provides support for the Nvidia GPUs on Linux and Windows systems. 

AWQ is different as compared to GPTQ as it offers faster Transformers-based inference with equivalent or better quality compared to the most commonly used GPTQ settings.

The model was fine-tuned on 1,000,000 entries of mainly GPT-4 generated data as well as other high-quality open datasets from the AI landscape.

Following is the parameter and model detail summary:
- Bits: 4
- Group Size: 128
- AWQ Dataset: VMware Open Instruct
- Sequence Length: 4096
- Size: 19.23GB

## Usage example
- Using transformers library

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TextStreamer

model_name_or_path = "TheBloke/Nous-Hermes-2-Yi-34B-AWQ"

tokenizer = AutoTokenizer.from_pretrained(model_name_or_path)
model = AutoModelForCausalLM.from_pretrained(
    model_name_or_path,
    low_cpu_mem_usage=True,
    device_map="cuda:0"
)
```
- Using Hugging Face Text Generation Inference (TGI)

```python
from huggingface_hub import InferenceClient

endpoint_url = "https://your-endpoint-url-here"  # Replace with your endpoint url
prompt = "Tell me about AI"

client = InferenceClient(endpoint_url)
response = client.text_generation(prompt,
                                  max_new_tokens=128,
                                  do_sample=True,
                                  temperature=0.7,
                                  top_p=0.95,
                                  top_k=40,
                                  repetition_penalty=1.1)
```
