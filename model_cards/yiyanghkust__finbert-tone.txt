## Description

The finbert-tone model is a text classification model trained using the transformers library in Python. It is designed for financial sentiment analysis and sentiment classification tasks. The model is based on the BERT architecture and has been fine-tuned for this specific application.

The model can be used to analyze the sentiment of financial texts and classify them into different sentiment categories. It is particularly suitable for tasks related to financial sentiment analysis.

The model has a total of 520,747 downloads and 117 likes on the Hugging Face model page.


## Usage example

Here is an example of how to use the finbert-tone model with the transformers library in Python:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

# Load the tokenizer and model
tokenizer = AutoTokenizer.from_pretrained("yiyanghkust/finbert-tone")
model = AutoModelForSequenceClassification.from_pretrained("yiyanghkust/finbert-tone")

# Tokenize the input text
input_text = "Stock prices are soaring and the company is showing strong financial growth."
inputs = tokenizer(input_text, return_tensors='pt')

# Make predictions
outputs = model(**inputs)
predictions = outputs.logits.argmax(dim=1)

# Get the predicted sentiment category
sentiment = predictions.item()
print("Predicted sentiment:", sentiment)
```

Please note that the example uses the `AutoTokenizer` and `AutoModelForSequenceClassification` classes from the transformers library to automatically load the tokenizer and model.

The model can be used to predict the sentiment of any given financial text.
