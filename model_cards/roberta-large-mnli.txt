## Description

The roberta-large-mnli model is a text classification model that uses the RoBERTa architecture. It is trained on the multi_nli, wikipedia, and bookcorpus datasets. The model has a total of 356,412,419 parameters. It is compatible with the transformers library in Python.

## Usage example

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer

model_name = "roberta-large-mnli"
model = AutoModelForSequenceClassification.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

text = "I like you. I love you."
inputs = tokenizer(text, return_tensors="pt")
outputs = model(**inputs)
```

Please note that the above usage example assumes that the transformers library is installed.
