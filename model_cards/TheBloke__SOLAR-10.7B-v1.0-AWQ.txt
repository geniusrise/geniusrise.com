# Model name

SOLAR-10.7B-v1.0-AWQ

## Links

- [Model Page](https://huggingface.co/TheBloke/SOLAR-10.7B-v1.0-AWQ)
- [Github Repo](https://github.com/TheBloke/SOLAR-10.7B-v1.0-AWQ)

## Description

The SOLAR-10.7B-v1.0-AWQ model is a text generation model based on the SOLAR-10.7B-v1.0 base model. It is trained using the transformers library with Python. The model is quantized using the AWQ (Approximate Weight Quantization) method with 4-bit precision. It has a total of 1,668,176,704 parameters.

The model is suitable for text generation tasks and belongs to the text-generation pipeline. It is compatible with the AutoTrain training library and supports safety measures with Safetensors.

## Usage example

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("TheBloke/SOLAR-10.7B-v1.0-AWQ")
model = AutoModelForCausalLM.from_pretrained("TheBloke/SOLAR-10.7B-v1.0-AWQ")

# Generate text
prompt = "Once upon a time,"
inputs = tokenizer(prompt, return_tensors="pt")
outputs = model.generate(inputs["input_ids"], max_length=100)
generated_text = tokenizer.decode(outputs[0])
print(generated_text)
```

Note: Replace `TheBloke/SOLAR-10.7B-v1.0-AWQ` with the appropriate model name according to your usage.
